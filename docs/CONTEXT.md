# Documentation Context

Inputs: [Planning Catalog](planning/README.md), [Contracts](contracts/README.md), [Task Index](../implementation/README.md) and relevant evidence.
Process: use [root routing](../AGENTS.md) or [ICM routing](map/AGENTS.md) to select one owning shelf. Scope/requirements live in planning, interfaces in contracts, execution evidence in progress and test reports, candidate technical decisions in [ADR records](adr/CONTEXT.md), skill research in skills.
Outputs: scoped English documents with synchronized references; [feature evidence](feature-parity.md) records implementation claims.
Human check: proposed behavior and observed evidence remain distinguishable. See [Agent Workflow](agent-workflow.md).
