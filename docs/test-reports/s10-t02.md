# S10-T02 — Compile bibliography and complete citations

**Status:** IN_PROGRESS (task implementation complete; pending sprint completion). **Branch:** `codex/sprint-10-academic-editing` tracking `origin/codex/sprint-10-academic-editing`. **Base:** `codex/sprint-09-history-review`. **Environment:** Linux (x86_64), Node 26+, pnpm 11.25.0. **Actual effort:** 8 h.

## Scope and acceptance evidence

- Implemented bibliography detection and execution helpers in `apps/tex-executor/src/bibliography.ts`:
  - `detectBibliographyBackend`: determines whether a document uses BibTeX or Biber (via biblatex).
  - `resolveBibliographyArgv`: generates allowlisted execution arguments for bibtex and biber while rejecting shell injection characters.
  - `parseBibLog`: parses `.blg` output to extract warnings, errors, and count of resolved entries.
  - `BIBLIOGRAPHY_FIXTURES`: positive fixtures for BibTeX and Biber multipass pipelines.
- Implemented citation extraction, duplicate detection, and completion in `packages/editor/src/citations.ts`:
  - `extractBibKeys`: extracts citation keys without mutating or normalizing source.
  - `findDuplicateBibKeys`: detects duplicate citation keys and reports line numbers.
  - `extractBibSummaries`: extracts title, author, and year for completion.
  - `getCitationQueryAtCursor`: detects `\cite`, `\citep`, `\citet`, `\autocite` contexts.
  - `insertCitation`: replaces partial citation query or inserts `\cite{key}`.
- Re-exported citations module from `@latex-collab/editor`.
- Added test suites:
  - `tests/integration/s10-t02.test.ts`: exercises backend detection, argv resolution, `.blg` parsing, key and summary extraction, duplicate detection, and cursor-based citation insertion.
  - `tests/regression/cmp-06/s10-t02.test.ts`: verifies CMP-06 multipass compilation fixtures for BibTeX and Biber.
  - `tests/regression/int-01/s10-t02.test.ts`: verifies INT-01 duplicate key detection and citation completion.
