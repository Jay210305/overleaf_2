## Scope and acceptance evidence

- Implemented SSRF-safe remote resource import in `apps/jobs/src/imports/remote-resource.ts`:
  - `isPrivateIp`: Robust IPv4 and IPv6 private, loopback, link-local, carrier-grade NAT, and documentation range validation, including IPv4-mapped IPv6 address inspection.
  - `validateRemoteUrl`: Protocol allowlisting (HTTP/HTTPS only), rejection of embedded credentials in URLs, blocking of cloud metadata endpoints (`169.254.169.254`, `metadata.google.internal`), optional domain allowlisting, and mandatory DNS revalidation before network connection.
  - `fetchRemoteResource`: Manual multi-hop redirect handling with per-hop URL and DNS revalidation, maximum redirect limit enforcement, content-type allowlisting, maximum byte size limit enforcement (both declared and streaming body byte counts), and timeout controls. Local credentials and cookies are strictly excluded from remote outbound requests.
