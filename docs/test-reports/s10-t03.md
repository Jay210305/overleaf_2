# S10-T03 — Index BibTeX and search local references

**Status:** IN_PROGRESS (task implementation complete; pending sprint completion). **Branch:** `codex/sprint-10-academic-editing` tracking `origin/codex/sprint-10-academic-editing`. **Base:** `codex/sprint-09-history-review`. **Environment:** Linux (x86_64), Node 26+, pnpm 11.25.0. **Actual effort:** 8 h.

## Scope and acceptance evidence

- Implemented lossless BibTeX parsing and local querying in `packages/latex/src/bib.ts`:
  - `parseBibTeX`: parses single-line and multi-line BibTeX entries without mutating or normalizing the source. Preserves exact `rawSource` for each entry.
  - Detects duplicate keys, recording exact occurrence counts and start lines.
  - `searchBibEntries`: performs fast local search across key, title, author, year, and DOI, supporting both substring queries and structured criteria.
  - `normalizeBibTeX`: available for explicit user request (e.g., sorting by key) while keeping source opening unnormalized by default (INT-08).
- Implemented accessible reference search UI in `apps/web/src/features/references/search.tsx`:
  - Search input with field filters (all, key, title, author, year).
  - Displays parsed entries and duplicate key alert banners.
  - Buttons for copying `\cite{key}` and inserting into active editor document.
  - Source preserved badge indicating zero background mutation.
- Added test suites:
  - `tests/integration/s10-t03.test.ts`: exercises entry parsing, duplicate detection, local field searching, structured filtering, and explicit normalization.
  - `tests/regression/int-01/s10-t03.test.ts`: validates duplicate key detection with line numbers.
  - `tests/regression/int-02/s10-t03.test.ts`: validates local reference queries across all standard academic fields.
  - `tests/regression/int-08/s10-t03.test.ts`: validates that opening `.bib` never normalizes or alters the source text.
