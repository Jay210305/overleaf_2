## Scope and acceptance evidence

- Implemented durable compile jobs repository and worker lifecycle management (`packages/db/src/repositories/compilations.ts`, `apps/jobs/src/compilation/worker.ts`).
- Created compilation routes in Fastify API (`apps/api/src/modules/compilations/routes.ts`):
  - `POST /api/v1/projects/:projectId/compilations`: enforces `projectAction: "COMPILE"`, checks mandatory `Idempotency-Key` (16..128 chars), freezes source revision via `freezeCompilationRevision`, and transactionally enqueues job with quota checks. Replay with identical key returns same job; conflict on modified parameters returns 400 `CONSTRAINT_VIOLATION`.
  - `GET /api/v1/projects/:projectId/compilations`: lists jobs with deterministic cursor-based pagination.
  - `GET /api/v1/projects/:projectId/compilations/:jobId`: retrieves single job view.
  - `DELETE /api/v1/projects/:projectId/compilations/:jobId`: cancels queued job immediately or requests cancellation (`cancel_requested`) on running jobs.
- Added database migration `0008-compile-jobs.sql` with check constraints `compile_jobs_status_check` and `compile_jobs_engine_check`, unique index `compile_jobs_actor_key_uidx`, active quota index `compile_jobs_active_quota_idx`, and worker claim index `compile_jobs_claim_idx`.
- Added test suites:
  - `tests/integration/s06-t01.test.ts`: exercises idempotency replay, payload modification conflict, missing/short idempotency key, active compile quota (429 QUOTA_EXCEEDED), role-based permissions (OWNER/EDITOR pass, VIEWER 403, outsider 404), worker lease claiming, heartbeat, cancellation, cursor pagination, and mock compiler execution.
  - `tests/regression/cmp-04/s06-t01.test.ts`: verifies database persistence across all 7 statuses, check constraint rejection of bogus status, and uniqueness constraint on idempotency keys.
  - `tests/regression/nfr-07/s06-t01.test.ts`: verifies concurrent compile quota per project and per user.
