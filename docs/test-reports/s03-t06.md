## Scope and behavior

- Implemented `apps/api/src/modules/projects/settings.ts` and registered routes in `apps/api/src/server.ts`:
  - `GET /api/v1/projects/:projectId/settings`: declares `projectAction: "READ"`. Returns `ProjectSettingsView` (`projectId`, `mainFileId`, `compiler`, `texliveImageVersion`, `autoCompile`, `timeoutSeconds`).
  - `PATCH /api/v1/projects/:projectId/settings`: declares `projectAction: "EDIT"`.
    - Enforces PRO-07: `mainFileId` must reference an active (not deleted) `.tex` file in the same project. Foreign nodes, non-.tex files, and folders are rejected with 400 `VALIDATION_ERROR`. Setting to `null` is supported.
    - Enforces EDT-12: `compiler` must be one of allowlisted engines (`pdflatex`, `xelatex`, `lualatex`, `latex`). Arbitrary command strings are rejected with 400.
    - Enforces timeout bounding policy: `timeoutSeconds` is strictly bounded between 5 and 120 seconds. Values exceeding limits reject with 400.
    - Optimistic concurrency: verifies `If-Match` against project `current_revision`, rejecting stale preconditions with 412. Atomically increments revision.
- Implemented `apps/web/src/features/projects/settings.tsx`:
  - Accessible settings form with root document selector, LaTeX engine dropdown, TeX Live version input, auto-compile toggle, and timeout bounds.
  - Client-side validation and clear error/success alerts.
