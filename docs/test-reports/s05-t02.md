**Status:** In progress; S05-T09/S05-T01 dependency acceptance and independent co-maintainer review remain open. **Branch:** `codex/sprint-05-assets-import-export` tracking `origin/codex/sprint-05-assets-import-export`. **Base:** `origin/main` `40f0870` plus `origin/codex/sprint-04-code-editor` `6549a09` through merge `d09db72`. **Environment:** Windows, Node 24, pnpm 11.25.0, Docker Compose PostgreSQL, Redis, MinIO and Mailpit, local Microsoft Edge. **Actual effort:** Not measured.

## Scope and acceptance evidence

- `FileUploader` adds a labeled multi-file picker and keyboard-operable drop target above the project file tree. Files run one at a time. Each row displays progress, completion, cancellation, retry and its own error. Only an API `201` completion refreshes the durable tree; no optimistic project node is created.
- The browser checks obvious unsafe names, unsupported extensions/MIME and the 25 MiB file limit before asking for a URL. The API remains the authority for permission, quota, hash, byte content and sibling collision. Web Crypto computes the SHA-256; XHR performs the signed private PUT with progress and abort; completion uses cookie, CSRF and a stable per-file idempotency key. A retry after uncertain completion first reuses the same upload ID and key.
- Local MinIO now sets `MINIO_API_CORS_ALLOW_ORIGIN` to the exact configured application origin. Its previous default allowed a foreign origin in preflight. The pinned MinIO returned HTTP 501 for bucket CORS configuration, so the global origin setting is the tested local boundary. The signed URL itself permits only PUT; CORS is a browser policy, not object authorization. Hosted storage CORS remains a deployment check.
- The real Edge journey selected two text files, observed both persist in the tree, then selected the first again. The UI showed a per-file collision error and PostgreSQL retained exactly one active node with that name. The workspace axe scan found no serious or critical violations. Component tests cover selection, drop denial, per-file progress, active and queued cancellation, retry after a lost completion response, and picker keyboard activation.
- Archive traversal, symlink and decompression-bomb validation belong to S05-T03/S05-T08; the browser rejects `.zip` here and no archive parser is introduced. Foreign project presign and content denials are enforced by S05-T01 server tests. S05-T02 does not broaden those server permissions.
