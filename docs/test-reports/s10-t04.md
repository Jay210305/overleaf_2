## Scope and acceptance evidence

- Implemented SyncTeX parsing and routing in `apps/api/src/modules/synctex/routes.ts`:
  - `parseSynctexData`: securely parses `.synctex` records (`Input`, `{page}`, `[box]`, `(box)`, `x point`) without invoking arbitrary shell processes.
  - `forwardLookup`: maps source `fileId`, `line`, and `column` to target PDF `page` and bounding boxes.
  - `inverseLookup`: maps PDF `page`, `x`, and `y` coordinates back to source `fileId`, `line`, and `column` by Euclidean distance.
  - Endpoints `POST /api/v1/projects/:projectId/synctex/forward` and `POST /api/v1/projects/:projectId/synctex/inverse`:
    - Enforce READ authorization on the project.
    - Validate schemas using `forwardRequestSchema` and `inverseRequestSchema`.
    - Validate project isolation: checks that `jobId` and `fileId` belong to the requested `projectId`.
- Implemented client navigation helper in `apps/web/src/features/pdf/source-navigation.ts`:
  - `navigateSourceToPdf`: issues typed forward SyncTeX API requests.
  - `navigatePdfToSource`: issues typed inverse SyncTeX API requests.
  - Coordinate transformations and documented tolerance checking (`SYNCTEX_POINT_TOLERANCE_PT = 5.0 pt`).
- Registered SyncTeX routes in `apps/api/src/server.ts`.
- Added test suites:
  - `tests/integration/s10-t04.test.ts`: exercises parser, forward mapping, inverse mapping, client navigation helpers, and scale/tolerance logic.
  - `tests/regression/cmp-07/s10-t04.test.ts`: verifies CMP-07 navigation accuracy, tolerance bounds, and missing file error handling.
