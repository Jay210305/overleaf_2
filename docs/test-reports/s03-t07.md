## Scope and behavior

- Implemented `packages/db/src/repositories/revisions.ts`:
  - `RevisionsRepository.createStructuralRevision`: creates immutable `project_revisions` record and associated `revision_items` pinning all active files. Computes canonical file paths from the tree hierarchy.
  - Manifest generation: sorts items deterministically by normalized path ascending, then nodeId ascending.
  - Canonical JSON stringification (`canonicalJsonStringify`) guarantees sorted keys and reproducible SHA-256 manifest hash matching NFR-06 requirements.
  - Generates pinned manifest key `projects/<projectId>/revisions/<revisionNo>.json` and monotonically advances `projects.current_revision`.
  - `RevisionsRepository.getRevision`: retrieves immutable revision, items and manifest.
  - `RevisionsRepository.compareRevisions`: implements COL-10 revision comparison, accurately reporting added, removed, modified, and unchanged files between any two project revision numbers.
