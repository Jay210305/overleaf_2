## Scope and acceptance evidence

- Implemented `ZoteroSyncAdapter` in `apps/jobs/src/sync/zotero.ts`:
  - Implements `ProviderAdapter` with capabilities `{ list: true, pull: true, push: false, individualReferenceImport: true }`.
  - Connect and credential validation: validates API key/token; handles `CREDENTIALS_MISSING` and `TOKEN_EXPIRED`.
  - Lists personal ("My Library") and group collections returning typed `Resource` items.
  - Pulls reference entries formatted in authentic `.bib` representation with SHA-256 revision hashing.
  - Read-only linked `.bib` refresh: performs line diff comparison against existing `.bib` content. When local manual edits conflict with remote changes, returns `status: 'conflict'` with conflict paths, preventing silent overwrites.
  - Push operations strictly return `CAPABILITY_UNSUPPORTED` to protect the read-only linked boundary.
  - Upstream rate limits return `RATE_LIMITED` with `retryable: true`.
- Implemented `ZoteroLibraryPanel` React UI in `apps/web/src/features/references/zotero.tsx`:
  - Visual status indicator (`DISCONNECTED`, `CONNECTED`, `SYNCING`, `SYNCED`, `CONFLICT`, `ERROR`).
  - Read-only Linked `.bib` badge explicitly communicating that external linked bibliographies remain read-only in the editor.
  - Dropdown selector for available Zotero libraries and collections.
  - Actions for linking library as `.bib` and refreshing linked `.bib`.
  - Conflict warning banner rendering diff/warning information when remote library changes diverge from local edits.
  - Server-side role enforcement: `VIEWER` and `REVIEWER` roles have link and refresh actions disabled with a viewing-only notice.
- Comprehensive test coverage:
  - `tests/integration/s13-t02.test.ts`: exercises adapter lifecycle, listing resources, pulling BibTeX, rate limiting, conflict protection, push rejection, and React UI rendering across permissions.
  - `tests/regression/int-03/s13-t02.test.ts`: validates INT-03 invariants for credentialed capability check, initial import, line-diff conflict detection, and push denial.
