# S03-T04 — Implement ID-based file tree mutations

**Status:** Completed. **Branch:** `codex/sprint-03-projects-files` tracking `origin/codex/sprint-03-projects-files`. **Base:** accepted S02 closure commit `415baa0`. **Environment:** Linux, Node 24, pnpm 11.25.0, PostgreSQL 17 and MinIO in local Compose. **Actual effort:** 8 h.

## Scope and behavior

- Implemented `apps/api/src/modules/files/tree.ts` and registered tree routes in `apps/api/src/server.ts`.
- `GET /api/v1/projects/:projectId/nodes`: reads tree view with active nodes, returning `TreeView` (`projectId`, `treeVersion`, `items`). Foreign project or outsider access returns 404.
- `POST /api/v1/projects/:projectId/nodes`: creates FOLDER or FILE node. Validates name safety (no empty, `.`, `..`, `/`, `\`, control chars). Validates parent is a FOLDER in the same project. Automatically registers `text_documents` row for text files. Rejects duplicate sibling names with 409 `REVISION_CONFLICT`. Respects optional `If-Match` optimistic locking. Atomically increments project `current_revision`.
- `PATCH /api/v1/projects/:projectId/nodes/:nodeId`: handles general node updates (rename and/or move).
- `PATCH /api/v1/projects/:projectId/nodes/:nodeId/move`: relocates node under a new parent or root (`targetParentId: null`). Rejects moving to self, moving to foreign parent (404), moving into non-folder (400), and cyclic moves into descendants via recursive ancestor check (400).
- `PATCH /api/v1/projects/:projectId/nodes/:nodeId/rename`: renames node, verifying sibling name collision (409) and optimistic concurrency via `If-Match` (412 on mismatch).
- `DELETE /api/v1/projects/:projectId/nodes/:nodeId`: soft-deletes node and all recursive descendants using a recursive CTE, nulls `projects.main_file_id` if pointing to any deleted descendant, and increments project `current_revision`. Enforces `If-Match` precondition check (412).
- Server-side project guard enforces session verification and `EDIT`/`READ` role checks across all endpoints.
