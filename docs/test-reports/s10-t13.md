## Scope and acceptance evidence

- Implemented content-aware cache key computation in `apps/jobs/src/compilation/cache.ts`:
  - `computeCompilationCacheKey`: hashes file manifest content hash, TeX compiler profile, container image digest, root file / options, and security policy version.
  - Changes to any of these input variables strictly invalidate the cache key (CMP-11).
- Implemented strict tenant authorization in `apps/jobs/src/compilation/cache.ts`:
  - `CompilationCache`: enforces project tenant boundary on lookups.
  - Throws `ForeignArtifactAccessDeniedError` if a foreign project attempts to claim or fetch another project's cached compilation artifacts.
  - `verifyManifestAndRevisionMatch`: validates that cached PDF artifacts strictly match the requested source revision and manifest hash (NFR-06).
  - Handles TTL expiration and explicit project-scoped cache invalidation.
- Added test suites:
  - `tests/integration/s10-t13.test.ts`: exercises deterministic SHA-256 key generation, invalidation across all dimensions, tenant isolation, revision matching, and TTL expiration.
  - `tests/regression/cmp-11/s10-t13.test.ts`: verifies CMP-11 that cache hits cannot authorize another project's artifacts and project invalidation functions properly.
  - `tests/regression/nfr-06/s10-t13.test.ts`: verifies NFR-06 that generated PDF sourceRevision and manifest hash match compilation input exactly.
