## Scope and acceptance evidence

- Implemented `apps/jobs/src/compilation/lifecycle.ts` defining state transition assertion `assertValidStatusTransition` and expired lease recovery `reconcileExpiredLeases`.
- Enforces state machine invariants from Compilation Contract:
  - Allowed transitions: `queued -> running/cancelled`, `running -> succeeded/failed/timed_out/cancel_requested`, `cancel_requested -> cancelled/succeeded/failed/timed_out`.
  - Forbids invalid transitions (e.g. running jobs cannot be marked cancelled directly; terminal states cannot be re-activated).
- Recovers expired worker leases after crashes without changing stable job ID:
  - Jobs in `cancel_requested` whose lease expired are finalized to `cancelled`.
  - Jobs in `running` with expired leases and attempts >= 3 are transitioned to `timed_out`.
  - Frees concurrent compilation quotas so pending or subsequent compile requests are no longer blocked.
- Added test suites:
  - `tests/integration/s06-t14.test.ts`: validates state machine transitions, recovery of expired dead worker jobs to `timed_out`, and finalization of `cancel_requested` jobs.
  - `tests/regression/cmp-04/s06-t14.test.ts`: validates terminal state immutability and forbids marking running jobs cancelled before termination.
  - `tests/regression/nfr-07/s06-t14.test.ts`: verifies that lease reconciliation releases active compile quotas.
