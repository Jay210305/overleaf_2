# S07-T08 — Apply live role and session revocation

**Status:** IN_PROGRESS (task implementation complete; pending sprint completion). **Branch:** `codex/sprint-07-durable-collaboration` tracking `origin/codex/sprint-07-durable-collaboration`. **Base:** `codex/sprint-06-trusted-compilation`. **Environment:** Linux (x86_64), Node 24+, pnpm 11.25.0, local Docker Compose PostgreSQL 17, Redis 7. **Actual effort:** 8 h.

## Scope and acceptance evidence

- Implemented `LiveRevocationManager` in `apps/collab/src/auth/revocation.ts` and integrated it with `CollabServer`.
- Enforced session revocation handling: revoking a session terminates all open collaboration sockets associated with that session with code 4401 (`SESSION_REVOKED`) and invalidates outstanding tickets in `TicketStore`.
- Enforced member removal handling: removing a member from a project terminates open sockets for that project with code 4403 (`MEMBER_REMOVED`), invalidates pending tickets, and stops delivery of newly broadcasted data (NFR-03).
- Enforced live role demotion: demoting an active user to VIEWER notifies the client via `role_updated`, immediately downgrades active socket permission to `action: "read"`, and rejects any subsequent write attempts with `PERMISSION_DENIED`.
- Enforced ACL precedence: ticket identity cannot override live database ACL. Stale tickets requesting write permissions for users now having VIEWER role are strictly rejected during ticket consumption.
- Added integration and regression test suites:
  - `tests/integration/s07-t08.test.ts`: verifies session revocation, member removal, and live role demotion to VIEWER.
  - `tests/regression/col-03/s07-t08.test.ts`: verifies VIEWER write rejection and that stale write tickets cannot bypass database ACL.
  - `tests/regression/nfr-03/s07-t08.test.ts`: verifies revoked users are disconnected immediately, receive no subsequent updates, and cannot acquire new tickets.
