# S04-T05 — Implement local undo search and shortcuts

**Status:** Completed. **Branch:** `codex/sprint-04-code-editor` tracking `origin/codex/sprint-04-code-editor`. **Base:** accepted S03 closure commit `f3684f7`. **Environment:** Linux, Node 24, pnpm 11.25.0, PostgreSQL 17 and MinIO in local Compose. **Actual effort:** 6 h.

## Scope and behavior

- Implemented `packages/editor/src/keymap.ts`:
  - `createEditorKeymap`: CodeMirror keybindings matching editor commands:
    - `Mod-s`: Trigger save action (`onSave`).
    - `Mod-Enter`: Trigger compilation (`onCompile`).
    - `Mod-/`: Toggle LaTeX comment (`% `) on current or selected lines.
    - `Mod-g`: Go to line dialog / action (`onGoToLine`).
    - `Mod-f` & `Escape`: Open and close search panel.
    - `Tab`: Indentation via `indentWithTab`.
    - `Mod-z` / `Mod-y` / `Mod-Shift-z`: Undo and redo commands.
  - `createScopedUndoManager`: Scoped `Y.UndoManager` configured with `trackedOrigins: new Set([localOrigin])`. Invariant: Local undo strictly reverts local origin mutations, never reversing changes from another collaborator (`EDT-04`).
  - `searchAcrossFiles`: Project-wide search across multiple buffers supporting case sensitivity, exact strings, and regex patterns (`EDT-08`).
  - `previewReplace`: Non-destructive replacement preview string generator (`EDT-08`).
