## Scope and acceptance evidence

- Implemented safe CRDT snapshot compaction in `apps/collab/src/persistence/snapshots.ts` (`SnapshotService`).
- Enforced row-level locking (`SELECT ... FOR UPDATE` on `text_documents`) to prevent concurrent race conditions during compaction.
- Enforced state verification step: decodes candidate snapshot bytes into a fresh `Y.Doc` and validates that plaintext and SHA-256 hash match the original state before persisting to `crdt_snapshots` and updating `text_documents.latest_snapshot_id`.
- Safely pruned covered updates (`seq <= targetSeq`) only after verified snapshot persistence.
- Verified that subsequent incremental updates build seamlessly on top of compacted snapshots.
- Validated NFR-01: Document state is completely preserved across snapshot compaction followed by server shutdown and restart.
- Added integration and regression test suites:
  - `tests/integration/s07-t12.test.ts`: verifies compaction, verification check, safe update pruning, and post-compaction replay.
  - `tests/regression/nfr-01/s07-t12.test.ts`: verifies durability across compaction and controlled server restart.
  - `tests/regression/col-01/s07-t12.test.ts`: verifies concurrent editing convergence on top of compacted snapshots.
