## Scope and acceptance evidence

- Implemented localized version-checked patching for academic constructs in `packages/editor/src/visual-academic-patch.ts`:
  - `applyTableCellPatch`: Pinpoints the exact character offset of the target cell within a tabular environment. Splices only the cell's content, preserving row delimiters `&`, line breaks `\\\\`, and all other rows and cells.
  - `applyFormulaPatch`: Pinpoints the exact character offset of display math formulas within `\[...\]`, `$$...$$`, or `\begin{equation}...\end{equation}`. Splices only the inner formula, preserving the outer delimiters.
  - `applyFigureCaptionPatch`: Pinpoints and replaces the caption text inside `\caption{...}`, leaving figure environment structure intact.
  - `applyFigureLabelPatch`: Pinpoints and replaces the label string inside `\label{...}`.
  - Concurrency & integrity guard: Verifies `expectedCellHash` / `expectedFormulaHash` / `expectedCaptionHash` / `expectedLabelHash` before mutating canonical `Y.Text`. Any concurrent conflict returns `conflict: true, reason: 'STALE_FRAGMENT_HASH'` and preserves old source 100% unaltered.
  - Out of bounds protection: Target row/col out of bounds returns `reason: 'CELL_NOT_FOUND'` with no state mutation.
- Exported `./visual-academic-patch` in `packages/editor/package.json` and `packages/editor/src/index.ts`.
- Added comprehensive integration and regression test suites:
  - `tests/integration/s11-t10.test.ts`: exercises table cell patching, display math formula patching, stale hash conflict detection, figure caption/label updates, and bounds error handling.
  - `tests/regression/edt-13/s11-t10.test.ts`: validates EDT-13 requirement that table and formula edits mutate only their designated region and stale hash conflict preserves canonical `Y.Text` unaltered.
