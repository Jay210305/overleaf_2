# S10-T05 — Create valid academic insertion snippets

**Status:** IN_PROGRESS (task implementation complete; pending sprint completion). **Branch:** `codex/sprint-10-academic-editing` tracking `origin/codex/sprint-10-academic-editing`. **Base:** `codex/sprint-09-history-review`. **Environment:** Linux (x86_64), Node 26+, pnpm 11.25.0. **Actual effort:** 6 h.

## Scope and acceptance evidence

- Implemented valid academic snippet generators in `packages/editor/src/snippets.ts`:
  - `generateFigureSnippet`: figure environment with `\centering`, `\includegraphics`, `\caption`, and optional `\label`.
  - `generateTableSnippet`: table environment with configurable columns/rows, tabular alignment, header, and caption/label.
  - `generateEquationSnippet`: equation environment with math expression and label.
  - `generateSectionSnippet`: section, subsection, and subsubsection snippets with corresponding labels.
  - `generateListSnippet`: itemize and enumerate list environments with formatted item bullets.
  - `generateLinkSnippet`: `\href` or `\url` hyperref snippets.
  - `generateRefSnippet`, `generateCiteSnippet`, `generateLabelSnippet`: validated academic cross-reference commands.
  - `insertSnippet`: replaces selection `[from, to]` with the generated snippet, strictly preserving document boundaries outside the selected span.
- Re-exported snippets module from `@latex-collab/editor`.
- Added test suites:
  - `tests/integration/s10-t05.test.ts`: exercises figure, table, equation, section, list, link, ref, cite, and label generation, boundary validation, and insertion replacement.
  - `tests/regression/edt-09/s10-t05.test.ts`: validates EDT-09 requirements for snippet syntax correctness and non-destructive range replacement.
