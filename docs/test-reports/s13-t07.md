# S13-T07 — Implement one permitted optional bibliography provider

**Status:** PASS. **Branch:** `codex/sprint-13-reference-providers` tracking `origin/codex/sprint-13-reference-providers`. **Base:** `codex/sprint-11-visual-editor`. **Environment:** Linux (x86_64), Node 26+, pnpm 11.25.0. **Actual effort:** 8 h.

## Scope and acceptance evidence

- Implemented `OptionalReferenceProviderAdapter` in `apps/jobs/src/sync/optional-reference-provider.ts`:
  - Based on the ADR-009 provider spike, implements the permitted open reference provider (`crossref`) supporting public scholarly collection listing, BibTeX retrieval, and remote revision calculation.
  - Enforces `isBlocked()` on unpermitted providers (`mendeley`, `papers`):
    - All operations (`connect`, `listResources`, `pull`, `push`, `getStatus`) strictly fail with `CAPABILITY_UNSUPPORTED` and detail containing `BLOCKED_BY_PROVIDER`.
    - Preserves system state without data corruption or fabricated adapter success.
  - For permitted open provider:
    - Capabilities: `list: true, pull: true, push: false, individualReferenceImport: true`.
    - Credential verification: handles valid access, credential expiration (`TOKEN_EXPIRED`), and error mapping.
    - Pulls verified canonical BibTeX citations with deterministic SHA-256 revision hash.
    - Push operations are strictly denied with `CAPABILITY_UNSUPPORTED`.
- Comprehensive test coverage:
  - `tests/integration/s13-t07.test.ts`: exercises open provider connection, collection listing, BibTeX pull, push rejection, credential expiry, and verifies that Mendeley and Papers fail across all operations with `BLOCKED_BY_PROVIDER`.
  - `tests/regression/int-04/s13-t07.test.ts`: validates INT-04 invariants ensuring only capabilities validated by ADR-009 are implemented, and unpermitted providers remain blocked with no claimed parity.
