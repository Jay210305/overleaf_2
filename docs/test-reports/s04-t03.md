## Scope and behavior

- Implemented `apps/web/src/features/editor/persistence.ts`:
  - `TextSaveCoordinator`: client-side coordinator tracking save lifecycle states (`saved`, `saving`, `offline`, `error`).
  - Invariant enforced: Local/IndexedDB/socket-only writes CANNOT be reported server-saved. Save status only reaches `saved` upon confirmed `DurableAck` from the server.
  - Exponential backoff retry queue on transient network failures and 503 DB outages; pending edits are preserved intact in queue and not dropped.
  - Visible terminal error handling for non-retryable errors:
    - 403 Forbidden on VIEWER/REVIEWER write attempts (`COL-03`).
    - 404 Deleted/missing file.
    - 409 Conflict on stale base vector, rejecting racing overwrites (`EDT-02`).
  - `createHttpSaveTransport`: standard HTTP PUT client sending updates to `/api/v1/projects/:projectId/files/:fileId/text` with CSRF protection and credentials.
