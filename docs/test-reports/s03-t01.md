## Scope and behavior

- Implemented `apps/api/src/modules/projects/routes.ts`, `apps/api/src/modules/projects/create.ts`, and updated `packages/db/src/repositories/projects.ts` and `packages/contracts/src/index.ts`.
- `POST /api/v1/projects`: creates new project with title, optional description, default compiler `pdflatex`, status `active`, revision 0. Automatically initializes root `main.tex` node and corresponding `text_documents` record, setting `projects.main_file_id`.
- `GET /api/v1/projects`: cursor-based pagination, deterministic ordering by `updatedAt` (descending) or `owner` (ascending) with ID tie-breaker. Supports filtering by `owned`, `shared`, `recent`, `archived`, `trashed`, and text search via query parameter `q`.
- `GET /api/v1/projects/:projectId`: declares `projectAction: "READ"`. Returns `ProjectView`. Foreign/absent projects return 404 (anti-enumeration).
- `PATCH /api/v1/projects/:projectId`: declares `projectAction: "EDIT"`. Enforces `If-Match` revision check returning 412 on mismatch. Rejects unsafe names or empty updates. Enforces that only OWNER can change project status.
- `DELETE /api/v1/projects/:projectId`: declares `projectAction: "DELETE"`. Soft-deletes project to status `trashed`. Subsequent reads return 404. Non-owners return 403.
