## Scope and acceptance evidence

- Implemented public compilation policy router and verification guard in `apps/jobs/src/compilation/public-policy.ts`:
  - `validatePublicCompilationPolicy(config)`: Fails startup if `untrustedCompileEnabled: true` is configured without verified isolated executor adapter (`ISOLATION_REQUIRED`).
  - Guards network denial (`NETWORK_ISOLATION_REQUIRED` if `networkDisabled: false`).
  - Guards shell-escape lockout (`SHELL_ESCAPE_FORBIDDEN` if `noShellEscape: false`).
  - Guards pinned TeX Live version against audited whitelist (`UNAUDITED_TEXLIVE_VERSION`).
  - `resolveCompilerExecutor(config, isJobUntrusted)`: Routes untrusted compilation requests to `IsolatedCompilerExecutor` with enforced isolation parameters, while blocking untrusted compilation with `UNTRUSTED_COMPILATION_DISABLED` when untrusted mode is turned off.
  - Verified routing and authentic PDF generation via `tests/integration/s15-t03.test.ts`, `tests/regression/pl-07/s15-t03.test.ts`, and `tests/regression/cmp-01/s15-t03.test.ts`.
