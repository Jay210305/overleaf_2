## Scope and acceptance evidence

- Implemented `apps/web/src/features/pdf/pdf-viewer.tsx`:
  - Zoom controls: stepped zoom-in (+25%), zoom-out (-25%), zoom percentage display, and zoom reset (100%).
  - Fit modes: Fit-to-width (`fit-width`) and Fit-to-page (`fit-page`).
  - Page navigation: previous page, next page, direct page number input bounded between 1 and `totalPages`.
  - Authorized download button: initiates secure download of `output.pdf`.
  - Provenance tracking: displays source revision number or label (`Rev #X`, `v1.0-draft`, etc.).
  - Stale fallback retention: when a subsequent compile fails, the viewer retains the last successful PDF build with a visible `OUTDATED` badge and compilation failure reason.
  - Empty state: clean placeholder when no PDF has been compiled yet.
- Added test suites:
  - `tests/integration/s06-t08.test.ts`: validates empty state, document rendering, zoom controls, fit modes, page navigation, download callback, and stale banner.
  - `tests/regression/cmp-03/s06-t08.test.ts`: validates interactive zoom, fit-width, fit-page, and page navigation controls.
  - `tests/regression/nfr-06/s06-t08.test.ts`: ensures source revision provenance is displayed and stale previous builds remain visible upon compile failure.
