# S10-T09 — Persist editor preferences symbols and layout

**Status:** IN_PROGRESS (task implementation complete; pending sprint completion). **Branch:** `codex/sprint-10-academic-editing` tracking `origin/codex/sprint-10-academic-editing`. **Base:** `codex/sprint-09-history-review`. **Environment:** Linux (x86_64), Node 26+, pnpm 11.25.0. **Actual effort:** 8 h.

## Scope and acceptance evidence

- Implemented editor preferences persistence in `apps/web/src/features/editor/preferences.tsx`:
  - `loadEditorPreferences`: loads theme, fontFamily, fontSize, tabWidth, wrap, autoClose, autocomplete, reducedMotion, and layout split configuration with safe default fallbacks.
  - `saveEditorPreferences`: persists configuration to browser storage across page reloads.
  - `useEditorPreferences`: React hook managing real-time preference updates and storage synchronization.
- Implemented mathematical symbols catalog and insertion in `packages/editor/src/symbols.ts`:
  - Catalog of standard LaTeX math symbols categorized into Greek, operators, relations, arrows, delimiters, and calculus/logic.
  - `searchSymbols`: searches symbols by command prefix, English name, or Unicode representation.
  - `formatSymbolInsertion`: automatically wraps symbols requiring math mode in `$...$` when inserted in text context.
- Implemented accessible symbol palette UI in `apps/web/src/features/editor/preferences.tsx`:
  - Tabbed category navigation, search bar, and grid of clickable symbol buttons.
  - Fully keyboard accessible and WCAG 2.2 AA compliant.
- Added test suites:
  - `tests/integration/s10-t09.test.ts`: exercises preference serialization across simulated reloads, symbol categorization and search, and contextual math mode wrapping.
  - `tests/regression/acc-05/s10-t09.test.ts`: verifies ACC-05 requirements that font, size, theme, tab width, wrap, and accessibility settings survive reload.
  - `tests/regression/edt-10/s10-t09.test.ts`: verifies EDT-10 requirements for categorized mathematical symbol search and insertion.
