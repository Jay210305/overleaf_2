## Scope and acceptance evidence

- Implemented project search and safe replacement in `apps/api/src/modules/search/routes.ts`:
  - `GET /api/v1/projects/:projectId/search`:
    - Enforces READ authorization.
    - Validates regex queries with `validateSafeRegex`: enforces 200 character pattern limit, syntax validation, and ReDoS protection (rejects catastrophic exponential backtracking patterns like `(a+)+`).
    - Searches project files and returns paginated `SearchView` matches with `fileId`, `path`, `line`, and matched `text`.
  - `POST /api/v1/projects/:projectId/search/replace`:
    - Enforces EDIT authorization.
    - Implements optimistic concurrency version guard: checks `project.currentRevision === body.expectedRevision`, rejecting stale replace previews with 409 `STALE_REVISION_CONFLICT`.
    - Performs atomic file replacement and returns `ReplaceResult` with `newRevisionId` and `replacements` count.
- Implemented accessible project search UI in `apps/web/src/features/search/project-search.tsx`:
  - Search and replace inputs with Regex toggle.
  - Results feed displaying matches by file and line.
  - Concurrency conflict handling with user-facing notification.
- Registered search routes in `apps/api/src/server.ts`.
- Added test suites:
  - `tests/integration/s10-t08.test.ts`: exercises ReDoS validation, length bounds, syntax error handling, case-insensitive and regex searches, and clean string replacements.
  - `tests/regression/edt-08/s10-t08.test.ts`: verifies EDT-08 requirements for ReDoS safety and previewed replacement correctness.
