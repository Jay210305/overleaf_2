## 2026-10-16 implementation and acceptance check

The live and read-only project views now request figure bytes through `GET /api/v1/projects/:projectId/files/:fileId/figure?path=...`. The route rechecks the current session and project READ role, derives a simple relative image path from the active source file and project tree, accepts only current binary PNG/JPEG/WebP nodes and project-scoped blob keys, and reads the private object with a 25 MiB bound. Failed, missing and revoked reads remain visibly **Unverified Asset**. A successful browser fetch produces a local blob URL and a real `<img>`; the URL is revoked on unmount. The source remains canonical Y.Text. Compatible inline/display math is typeset with KaTeX 0.19.0 (`trust: false`); an unsupported macro is shown as literal formula source, and the PDF authority label remains. Citation chips continue to show literal keys without mutating source.
