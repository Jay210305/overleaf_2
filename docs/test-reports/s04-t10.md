## Scope and behavior

- Implemented `apps/api/src/modules/text/routes.ts` and registered routes in `apps/api/src/server.ts`:
  - `GET /api/v1/projects/:projectId/files/:fileId/text`: declared `projectAction: "READ"`. Returns `TextState` (`{ fileId, updateBase64, stateVectorBase64, persistedSeq }`).
  - `PUT /api/v1/projects/:projectId/files/:fileId/text`: declared `projectAction: "EDIT"`. Accepts `ApplyTextUpdateInput` (`{ updateBase64, baseStateVectorBase64 }`), commits update under monotonic sequence allocation, and returns `TextState` with `DurableAck` (`text.durable_ack`) covering the committed state vector.
  - Server-side authorization & CSRF guards:
    - OWNER and EDITOR are authorized for read and edit.
    - REVIEWER and VIEWER can read but are denied on PUT with 403 `PROJECT_PERMISSION_DENIED` (`COL-03`).
    - Stale base state vector rejected with 409 `REVISION_CONFLICT` (`EDT-02`).
    - Unauthenticated requests return 401 `AUTHENTICATION_REQUIRED`.
    - Foreign/absent resources return anti-enumeration 404 `RESOURCE_NOT_FOUND`.
