## Scope and acceptance evidence

- Implemented debounced auto-compile coordinator in `apps/web/src/features/compilation/auto-compile.ts`:
  - `AutoCompileController`: handles rapid keystroke debounce with configurable delay (clamped between 500ms and 10000ms).
  - Enforces policy-bounded compilation timeout (max 60s per system policy).
  - When compilation is in flight, incoming edits mark at most one queued successor rather than interrupting the running job.
  - Automatically triggers the queued successor upon completion of the active compilation.
- Implemented compilation queue coalescing in `apps/jobs/src/compilation/coalesce.ts`:
  - `InMemoryJobCoalescer`: guarantees that active running jobs are never aborted or killed by incoming typing bursts.
  - Holds at most one queued successor behind a running job; new requests coalesce into the existing queued successor with the latest document revision snapshot (CMP-08).
  - `coalesceCompileJobInDatabase`: atomic PostgreSQL transactional equivalent using project compile job state.
- Added test suites:
  - `tests/integration/s10-t12.test.ts`: exercises keystroke debounce, successor triggering after active compilation finishes, and queue coalescing.
  - `tests/regression/cmp-08/s10-t12.test.ts`: verifies CMP-08 that bursts of rapid typing do not interrupt or cancel actively running jobs.
  - `tests/regression/edt-12/s10-t12.test.ts`: verifies EDT-12 timeout bounding (60s policy clamp), debounce limits, and disabled state handling.
