# S05-T03 — Archive validation and idempotent import jobs

**Status:** In progress; independent co-maintainer review remains open. **Branch:** `codex/sprint-05-assets-import-export` tracking `origin/codex/sprint-05-assets-import-export`. **Base:** `origin/main` at `40f0870` plus `origin/codex/sprint-04-code-editor` at `6549a09` through merge `d09db72`. **Environment:** Windows, Node 24.20.0, pnpm 11.25.0 via corepack, Docker Compose PostgreSQL, Redis, MinIO and Mailpit. **Actual effort:** Not measured.

## Scope and acceptance evidence

- `packages/db/migrations/0006-import-jobs.sql` creates `import_jobs` (actor, hashed idempotency key, archive fingerprint, server-only archive key, status, lease/attempt metadata, versioned manifest, redacted error code, eventual project ID, sweep flag) with a unique actor/key constraint, a claim index and a sweep index. A trailing `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` plus `DROP INDEX IF EXISTS` repairs databases where an earlier draft of this migration was already applied, following the 0005 precedent. The next free number stays 0007 for S05-T12.
- `packages/db/src/repositories/import-jobs.ts` (exported as `@latex-collab/db/repositories/import-jobs`) implements reserve-before-copy idempotency: same actor/key/fingerprint returns the same job (including failed jobs); same key with changed input throws a non-retryable conflict; concurrent reserves serialize on the unique constraint. `enqueue` moves staging to queued only when the verified copy matches the reservation. `claimNext` atomically claims the oldest queued or lease-expired job with `FOR UPDATE SKIP LOCKED`; `complete`/`fail` require the held claim; `release` returns a lease for crash recovery. `listUnswept`/`markArchiveSwept` bound rejected-byte reclamation so unbounded failed rows cannot starve newer ones from the sweep window. The repository writes no project, node or text rows. A matching Drizzle table mirrors the SQL.
- `packages/storage/src/content-policy.ts` is the new server-only shared policy consumed by the S05-T01 upload routes (refactored to import it; route behavior unchanged) and the ZIP validator: one extension/MIME map, byte/node/archive limits, strict UTF-8 text and binary-signature checks, deterministic `imports/<actorId>/uploads|jobs` key builders and actor-scope assertion. Never imported by browser code. `validateKey` additionally allows the explicit `imports/` prefix; callers (not the adapter) enforce actor/job scope and never accept client keys.
- `apps/jobs/src/imports/zip.ts` validates archives with exact-pinned `yauzl` 3.4.0 (MIT, verified version/license/API from the registry and upstream README: central-directory parser, lazy entries, strict names, Promise API). It decodes raw entry names itself as strict UTF-8, rejects traversal/absolute/drive/backslash/empty/dot segments/control characters/percent-encoded traversal/non-NFC/duplicate paths as 400, symlinks and non-regular/special/encrypted/unsupported-method entries plus nested `.zip` as 422, and enforces 25 MiB compressed input, 100 MiB total expansion, 2000 nodes including implied directories, 25 MiB per file and 100:1 per-entry expansion as 413, aborting mid-stream with independent counters. SHA-256 and CRC-32 are computed from actual decompressed bytes and compared against the central directory; content bytes pass the shared policy. The sorted versioned manifest stores paths, kind, MIME, size and SHA-256 only — no source bytes. Empty archives are 422.
- `apps/jobs/src/imports/worker.ts` runs a bounded private pass: claim, re-verify the database-bound archive (existence, size, SHA-256 over a bounded read), validate, then complete or fail with a redacted code. Unexpected storage/database outages release the claim for a later pass instead of failing the job. Rejected archives are deleted best-effort and re-swept from the still-durable failed row; validated archives are retained for S05-T10. Wired as `pnpm --filter @latex-collab/jobs imports:validate --once`.
- `tests/integration/s05-t03.test.ts` (9 tests) covers reserve/claim/idempotency/conflict/concurrency/lease recovery, a valid nested archive (manifest paths/hashes, no project/node/text mutation, archive retained), traversal rejection with outage-spanning sweep retry, metadata-lie bombs and missing/mismatched bytes. `tests/regression/pro-02/s05-t03.test.ts` (2 tests) covers retry idempotency and failed-job addressability. `tests/regression/pro-10/s05-t03.test.ts` (6 tests) covers the hostile battery: 10 unsafe-path shapes, duplicates, symlink/encrypted/bad-method, forged sizes/CRCs, over-budget expansion and nested archives/unsupported types/invalid text/empty archives. Archive fixtures are hand-built in `tests/helpers/zip-fixtures.ts` for exact hostile control (no writer dependency). Because fixtures share local services and the worker is global by design, assertions wait for each job's terminal state instead of counting which pass moved it; parallel workers only accelerate the outcome.
