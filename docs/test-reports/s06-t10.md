## Scope and acceptance evidence

- Implemented and verified genuine document compilation test fixtures:
  - Standard article fixture: compiles cleanly into genuine PDF (`%PDF-1.5` magic bytes) and logs.
  - Cross-references document fixture: tracks multi-pass cross references (`\ref`, `\label`) and extracts warning diagnostics on unresolved references.
  - Syntax error fixture: triggers deliberate LaTeX syntax failure (`\invalidmacro`), parses error line and message, and produces no output PDF.
  - Output retention invariant: when a subsequent compile fails with syntax errors, the prior valid PDF and artifact set are retained intact in storage, accessible via HTTP API, and displayed as stale in the PDF viewer.
  - Complete output log sanitization: `compile.log` artifact bytes are cleansed of host directories and private credentials before storage.

  - `tests/regression/cmp-02/s06-t10.test.ts`: validates that syntax errors yield file/line diagnostics and zero credentials appear in logs or diagnostics.
