**Status:** Completed. **Branch:** `codex/sprint-04-code-editor` tracking `origin/codex/sprint-04-code-editor`. **Base:** accepted S03 closure commit `f3684f7`. **Environment:** Linux, Node 24, pnpm 11.25.0, PostgreSQL 17 and MinIO in local Compose. **Actual effort:** 8 h.

## Scope and behavior

- Implemented `apps/api/src/modules/text/text-document-service.ts`:
  - `DefaultTextDocumentService` implementing `TextDocumentService` contract (`load`, `apply`, `getTextContent`).
  - Strict server-side authorization: verifies project existence, active status, membership, role permissions (OWNER and EDITOR allowed to edit; VIEWER and REVIEWER restricted to read-only returning 403; foreign users return anti-enumeration 404).
  - Validates decoded Yjs mutation payload with strict 1 MiB frame cap and sandbox test before database transaction.
  - Per-file transaction locking on `text_documents` row (`FOR UPDATE`) to prevent sequence allocation races.
  - Detects stale base state vector returning 409 `REVISION_CONFLICT` in single-editor flow without overwriting or corrupting document state.
  - Reconstructs document state by replaying snapshots from `crdt_snapshots` and sequential updates from `crdt_updates` with zero divergence from a second text column.
  - Zero acknowledged edits lost after cold API restart (`NFR-01`).
