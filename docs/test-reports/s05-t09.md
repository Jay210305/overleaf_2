# S05-T09 — Quota and orphan object cleanup

**Status:** In progress; S05-T01 dependency and independent co-maintainer review remain open. **Branch:** `codex/sprint-05-assets-import-export` tracking `origin/codex/sprint-05-assets-import-export`. **Base:** `origin/main` `40f0870` plus `origin/codex/sprint-04-code-editor` `6549a09` via merge `d09db72`. **Environment:** Windows, Node 24, pnpm 11.25.0, Docker Compose PostgreSQL, Redis, MinIO and Mailpit. **Actual effort:** Not measured.

## Scope and observed behavior

- The private jobs app runs a one-shot `storage:gc` command or a recurring hourly pass. It lists only database-known project upload/blob prefixes with paged S3 listing. Per candidate it requires at least 10 minutes of object age, rechecks metadata and references under the project row lock, and deletes at most 25 objects per pass by default. It emits counts only, with no object keys or source bytes.
- Expired upload staging and orphan blobs in projects without revisions can be removed. Active upload intents, current nodes, artifact references and revision-bearing projects retain bytes. Failed deletes are counted and retried on a later pass. Keys for projects absent from PostgreSQL are untouched.
- The real API/DB regression shows two completions competing for the last project byte result in one `201` and one `413`, with exactly one node and 100 MiB total. A separate regression accepts the 2,000th node and rejects the next presign with `413`. This verifies the S05-T01 quota boundary; no quota calculation was moved into the jobs app.
- A regression reproduced `revision_items.node_id ON DELETE CASCADE`: physically deleting a node also removed its historical item row while leaving the revision. The cleanup therefore conservatively retains **all** blobs in any project with a revision. GAP-17 tracks durable immutable references and later reclamation. This preserves historical bytes but can retain orphans indefinitely until that schema work is complete.
- ZIP traversal, symlink and decompression-bomb handling belong to S05-T03/S05-T08; no archive parser is introduced here. S05-T01 covers upload filename/MIME/hash denials and foreign presign authorization.
