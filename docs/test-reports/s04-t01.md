# S04-T01 — Create LaTeX CodeMirror extensions

**Status:** Completed. **Branch:** `codex/sprint-04-code-editor` tracking `origin/codex/sprint-04-code-editor`. **Base:** accepted S03 closure commit `f3684f7`. **Environment:** Linux, Node 24, pnpm 11.25.0, PostgreSQL 17 and MinIO in local Compose. **Actual effort:** 8 h.

## Scope and behavior

- Implemented `packages/editor/src/latex-extension.ts`, `packages/editor/src/index.ts`, `apps/web/src/features/editor/latex-code-editor.tsx`, and exported them via `@latex-collab/editor`.
- CodeMirror 6 extensions:
  - File extension mode resolver (`getModeForFilename`) supporting LaTeX (`.tex`), BibTeX (`.bib`), Style (`.sty`, `.cls`, `.dtx`), and plain text.
  - Custom token decorations and syntax highlighting for LaTeX commands, environments (`\begin`, `\end`), math blocks (`$...$`, `$$...$$`), comments (`%`), and BibTeX entry/fields.
  - Code folding service for LaTeX environments (`\begin{env} ... \end{env}`).
  - Line numbers, active line gutter, indentation unit, and bracket matching.
  - Light and dark themes matching editor styling requirements.
  - Read-only protection mode.
- React editor component `LatexCodeEditor` in `apps/web/src/features/editor/latex-code-editor.tsx`:
  - Mounts CodeMirror 6 with live document synchronization.
  - Displays mode and line/col cursor positions in status bar.
  - Displays save status indicator (`saved`, `saving`, `offline`, `error`).
  - Displays explicit banners for 403 viewer mode, 404 deleted files, 409 stale base conflicts, and 503 database outage without falsely claiming saved.
  - Preserves complex Unicode source (accents, math symbols, emojis, Spanish, RTL) without lossy conversion.
