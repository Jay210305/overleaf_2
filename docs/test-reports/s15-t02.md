# S15-T02 — Audit TeX escape and resource attacks

**Status:** PASS. **Branch:** `codex/sprint-15-public-hardening` tracking `origin/codex/sprint-15-public-hardening`. **Base:** `codex/sprint-14-git-and-optional-features`. **Environment:** Linux (x86_64), Node 26+, pnpm 11.25.0. **Actual effort:** 8 h.

## Scope and acceptance evidence

- Audited and verified containment of TeX escape vectors and adversarial resource attacks under Gate 5 (`IsolatedCompilerExecutor`):
  - **ADV-01 (Shell Escape):** Verified `-no-shell-escape` is strictly enforced and cannot be overridden by input documents (`\write18` commands are rejected).
  - **ADV-02 (Directory Traversal):** Verified attempts to escape working directory boundaries via relative paths (`../../etc/shadow`) or absolute paths (`/etc/passwd`) are rejected prior to compilation.
  - **ADV-03 (Resource Exhaustion / Infinite Loops):** Verified jobs with recursive macro expansion or infinite loops terminate cleanly at the configured deadline (`limits.timeoutSeconds`), exiting safely without hung processes.
  - **ADV-04 (Network Isolation):** Verified network denial parameter (`networkDisabled: true`) is enforced for compiler processes.
  - **ADV-05 (Secret Hygiene):** Verified all ambient database, cache, storage, and session secrets are expunged from compiler sub-processes (`PL-07`).
  - **NFR-07 (Concurrent Jobs & Quotas):** Verified concurrent compilation jobs operate in independent isolated workspaces with separate timeouts and scratch size limits, preventing cross-tenant interference.
