## Scope and acceptance evidence

- Implemented minimal version-checked source patching in `packages/editor/src/visual-patch.ts`:
  - `applyVisualPatch`: applies localized character-level splices directly to `Y.Text` within transactional boundaries.
  - Verifies exact fragment hash matching `patch.expectedTextHash` before mutating.
  - Stale fragment hash (due to concurrent modifications) safely rejects the patch with `conflict: true, reason: 'STALE_FRAGMENT_HASH'`, preventing silent overwrite and preserving source integrity.
  - Range bounds checking prevents out-of-bounds corruption with `reason: 'RANGE_OUT_OF_BOUNDS'`.
  - Non-destructive localized diff: verifies that code before `start` and after `end` is 100% byte-for-byte identical; completely avoids whole-document regeneration.
  - `reanchorRange`: provides re-anchoring calculations when non-overlapping edits precede the target region.
- Exported `./visual-patch` from `packages/editor/package.json` and `packages/editor/src/index.ts`.
