# S10-T11 — Add local spell checking and static error help

**Status:** IN_PROGRESS (task implementation complete; pending sprint completion). **Branch:** `codex/sprint-10-academic-editing` tracking `origin/codex/sprint-10-academic-editing`. **Base:** `codex/sprint-09-history-review`. **Environment:** Linux (x86_64), Node 26+, pnpm 11.25.0. **Actual effort:** 6 h.

## Scope and acceptance evidence

- Implemented LaTeX-aware local spell checking in `packages/editor/src/spellcheck.ts`:
  - `checkSpelling`: parses LaTeX text and performs local spell checking against a built-in offline dictionary and optional project-specific custom word list.
  - Automatically identifies and masks LaTeX commands (`\section`, `\textbf`, `\begin`, `\end`, `\documentclass`, etc.), technical arguments (`\cite{...}`, `\label{...}`, `\ref{...}`, `\input{...}`), inline/display math environments (`$...$`, `\begin{equation}...\end{equation}`), and comments (`%...`).
  - Implements Levenshtein distance calculation to offer prioritized typo suggestions without external services (EDT-11).
- Implemented static offline error help in `apps/web/src/features/help/latex-help.tsx`:
  - `STATIC_ERROR_CATALOG`: comprehensive offline diagnostic catalog covering common TeX errors (undefined control sequences, missing $, mismatched environments, file not found, overfull/underfull boxes, emergency stop, missing \begin{document}).
  - `lookupErrorHelp`: maps compiler error strings directly to structured diagnoses and suggested fixes without network calls.
  - `searchHelpCatalog`: searchable offline index of errors and commands.
  - `LatexHelpPanel`: accessible React UI presenting offline diagnoses first, with strict explicit consent required for AI features and zero external telemetry (EDT-14).
- Added test suites:
  - `tests/integration/s10-t11.test.ts`: exercises spell check masking, suggestions, custom words, and static help lookup.
  - `tests/regression/edt-11/s10-t11.test.ts`: verifies EDT-11 requirements that LaTeX commands, arguments, and markup remain unchanged and unflagged.
  - `tests/regression/edt-14/s10-t11.test.ts`: verifies EDT-14 offline guarantee with zero network requests.
