**Status:** Completed. **Branch:** `codex/sprint-03-projects-files` tracking `origin/codex/sprint-03-projects-files`. **Base:** accepted S02 closure commit `415baa0`. **Environment:** Linux, Node 24, pnpm 11.25.0, PostgreSQL 17 and MinIO in local Compose. **Actual effort:** 8 h.

## Scope and behavior

- Implemented `apps/web/src/features/files/file-tree.tsx` providing an accessible, interactive file tree component:
  - Fetches and displays hierarchical tree from `GET /api/v1/projects/:projectId/nodes`.
  - Supports expanding/collapsing folders, breadcrumb navigation, and node selection (`onSelectNode`).
  - Toolbar and context menu buttons for: "New file", "New folder", "Rename", "Move", and "Delete".
  - Actions open accessible modal dialogs (`role="dialog"`, `aria-modal="true"`, `aria-labelledby="dialog-title"`).
  - Client-side validation prevents submitting unsafe names (`.`, `..`, `/`, `\`) before dispatching requests.
  - Submits mutations with `If-Match` optimistic concurrency headers and CSRF tokens.
  - Automatically recovers from 400, 403, 409, and 412 responses: displays clear inline error alerts (`role="alert"`) and re-synchronizes the tree with the API, preventing phantom or duplicate nodes.
  - WCAG 2.2 AA accessibility (NFR-08): semantic landmarks (`role="region"`, `role="toolbar"`, `role="navigation"`), tree roles (`role="tree"`, `role="treeitem"`, `role="group"`), ARIA state attributes (`aria-selected`, `aria-expanded`, `aria-level`), polite live announcements (`aria-live="polite"`), and full keyboard navigation (ArrowDown, ArrowUp, ArrowRight, ArrowLeft, Enter/Space).
