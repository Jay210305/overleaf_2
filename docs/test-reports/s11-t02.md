# S11-T02 — Create source AST projection and range map

**Status:** PASS. **Branch:** `codex/sprint-11-visual-editor` tracking `origin/codex/sprint-11-visual-editor`. **Base:** `codex/sprint-10-academic-editing`. **Environment:** Linux (x86_64), Node 26+, pnpm 11.25.0. **Actual effort:** 8 h.

## Scope and acceptance evidence

- Implemented conservative LaTeX source AST projection and bidirectional range mapping in `packages/latex/src/visual-ast.ts`.
- Implemented node types with exact 0-indexed character offsets `[start, end]` and SHA-256 fragment hashes:
  - Headings (`\section`, `\subsection`, `\subsubsection`) with inner title range and outer command preservation.
  - Paragraphs with inline spans: bold (`\textbf`), italic (`\textit`, `\emph`), inline math (`$ ... $`, `\( ... \)`), citation (`\cite`), and cross-reference (`\ref`, `\eqref`).
  - Lists (`itemize`, `enumerate`) with individual item markers and content ranges.
  - Display math (`\[ ... \]`, `$$ ... $$`, `\begin{equation} ... \end{equation}`).
  - Figures (`\begin{figure}`, `\includegraphics`, `\caption`, `\label`).
  - Tables (`\begin{tabular}`, rows, and cells).
  - Literal fallbacks for preamble, verbatim, TikZ, unknown macros, and complex environments.
- Implemented non-destructive AST serialization (`serializeVisualAst`) verifying 100% byte-for-byte fidelity with the original source.
- Implemented bidirectional lookups: `findNodeAtOffset` and `findNodeById`.
- Added contract schemas in `packages/contracts/src/index.ts`: `visualNodeKindSchema`, `visualPatchSchema`, `visualPatchResultSchema`.
- Exported `./visual-ast` from `packages/latex/package.json` and `packages/latex/src/index.ts`.
- Added comprehensive integration and regression test suites:
  - `tests/integration/s11-t02.test.ts`: exercises basic supported nodes, academic elements, literal fallbacks, bidirectional range map lookups, and malformed syntax resilience.
  - `tests/regression/edt-13/s11-t02.test.ts`: validates EDT-13 invariants for range preservation, unsupported literal fallback, and non-destructive failure recovery.
