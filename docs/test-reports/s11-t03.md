## Scope and acceptance evidence

- Implemented accessible React components for basic visual LaTeX nodes in `apps/web/src/features/visual/basic-nodes.tsx`:
  - `VisualHeading`: semantic `h1`, `h2`, `h3` tags with inline keyboard/click editing, preserving outer LaTeX commands and emitting versioned change events with fragment hashes.
  - `VisualParagraph`: formatted paragraph container supporting inline spans (`VisualSpanView`) for `bold` (`strong`), `italic` (`em`), inline math, citations, references, and plain text.
  - `VisualList` and `VisualListItemView`: interactive itemize (`ul`) and enumerate (`ol`) lists with editable item contents and item marker preservation.
  - `BasicVisualNodesView`: container projection rendering AST node lists with read-only guards.
- Enforced read-only protection: when `readOnly = true`, edit handlers, input fields, and textareas remain disabled/unrendered.
- Maintained exact whitespace and raw source invariants without synthetic DOM corruption.
- Added comprehensive integration and regression test suites:
  - `tests/integration/s11-t03.test.ts`: exercises heading rendering/editing, paragraph span formatting, list item interactions, and read-only enforcement.
  - `tests/regression/edt-13/s11-t03.test.ts`: validates EDT-13 invariants that basic visual node projection preserves raw LaTeX strings and isolates item content without destructive normalization.
