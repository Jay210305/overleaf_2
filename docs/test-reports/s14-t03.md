## Scope and acceptance evidence

- Implemented Git Smart HTTP protocol engine and packfile generation in `apps/git-bridge/src/protocol.ts`:
  - Packet-line (`pkt-line`) encoding, decoding, and `0000` flush frame demarcation.
  - Pure TypeScript Git object generation: blobs (`OBJ_BLOB`), trees (`OBJ_TREE`), and commit objects (`OBJ_COMMIT`) with canonical SHA-1 identifiers.
  - Git packfile binary builder assembling header, variable-length object length headers, zlib compression, and 20-byte SHA-1 checksum trailer.
  - Sideband-64k channel 1 streaming chunker for multiplexed upload-pack negotiations.
  - Smart HTTP ref advertisement builder for `git-upload-pack` and `git-receive-pack`.
  - Receive-pack command parser extracting client old/new SHAs and target refs.
  - Strict fast-forward verification (`verifyFastForward`): validates that client old SHA matches server project tip, rejecting stale or divergent push attempts with `[rejected] main -> main (fetch first)`.
- Integrated protocol engine into `apps/git-bridge/src/server.ts` to power actual Git CLI operations.
- Validated real Git CLI interaction in `tests/integration/s14-t03.test.ts`:
  - `git clone` creates local repository, checkouts `main.tex`, and displays repository log.
  - `git push` successfully commits and advances remote project tip for valid fast-forward, unpacks incoming delta/packfile objects, generates canonical Yjs mutations, and writes project revision to PostgreSQL.
  - Subsequent fresh `git clone` into a second directory succeeds and verifies full round-trip commit and file content integrity (`% Real push test comment`).
  - Stale non-fast-forward push is rejected, maintaining remote state safely without corruption or data loss.
  - Non-UUID repository path requests return clean 404 without database SQL exceptions.
- Implemented and verified in `apps/git-bridge/src/protocol.ts` and `tests/regression/int-06/s14-t03.test.ts`:
  - Git delta instructions (`applyGitDelta`): decodes copy and insert commands, reconstructing target objects from base representations.
  - Packfile unpacking (`unpackPackfile`): parses PACK headers, decompresses commits/trees/blobs, resolves deltas against base snapshot objects, and extracts project file trees.
