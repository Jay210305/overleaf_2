# S11-T06 — Create literal fallback for unsupported TeX

**Status:** PASS. **Branch:** `codex/sprint-11-visual-editor` tracking `origin/codex/sprint-11-visual-editor`. **Base:** `codex/sprint-10-academic-editing`. **Environment:** Linux (x86_64), Node 26+, pnpm 11.25.0. **Actual effort:** 6 h.

## Scope and acceptance evidence

- Implemented literal fallback rendering and non-destructive fallback components in `apps/web/src/features/visual/fallback-node.tsx`:
  - `VisualLiteralFallback`: Renders unsupported LaTeX constructs (preamble, unknown macros, complex environments, verbatim blocks, TikZ vector graphics, syntax errors) as clear, styled literal blocks.
  - Distinguishes reason tags with distinct semantic badges (`Document Preamble / Setup`, `Custom / Unsupported Macro`, `Complex LaTeX Environment`, `Verbatim Block`, `TikZ Graphic`, `Unparsed LaTeX Syntax`).
  - Non-destructive guarantee: never alters, parses away, or corrupts unsupported code; source round-trip remains 100% byte-for-byte identical.
  - Provides "Copy TeX" and "Edit in Code Mode" action buttons that pass the exact character offset back to the editor view.
  - Supports in-place raw editing with optimistic concurrency verification via `node.hash`.
  - Enforces `readOnly` protection to prevent edits in view-only contexts.
  - `FallbackNodesView`: Filtered container view rendering all literal fallback nodes in a document.
- Added comprehensive integration and regression test suites:
  - `tests/integration/s11-t06.test.ts`: exercises preamble and TikZ rendering, "Edit in Code Mode" offset callbacks, raw localized editing with concurrency guard, and read-only lockdown.
  - `tests/regression/edt-13/s11-t06.test.ts`: validates EDT-13 requirement that unsupported constructs (preamble, TikZ, verbatim, custom macros) never mutate or discard raw TeX and preserve 100% byte fidelity.
