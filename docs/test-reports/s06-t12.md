## Scope and acceptance evidence

- Documented security boundary in `docs/adr/trusted-runtime-spike.md`:

  - `-interaction=nonstopmode` and `-file-line-error` guarantee automated diagnostic extraction without hanging processes.
  - Process limits defined: 60 s timeout, 512 MiB memory limit, 1 CPU core, 25 MiB maximum output.
  - Credential stripping enforced: zero DB, Redis, S3, or API tokens passed to the compiler runtime.
  - Multi-tenant / public untrusted mode marked fails-closed (`IsolatedCompilerExecutor` throws `NOT_IMPLEMENTED`).
