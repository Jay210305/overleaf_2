## Scope and acceptance evidence

- Implemented `DropboxBidirectionalAdapter` in `apps/jobs/src/sync/dropbox-bidirectional.ts`:
  - Implements the typed `ProviderAdapter` contract with `DROPBOX_BIDIRECTIONAL_CAPABILITIES` (`list: true`, `pull: true`, `push: true`, `individualReferenceImport: false`).
  - Supports connect, disconnect, resource listing, pull, push, and getStatus.
  - Pull synchronization:
    - Performs path traversal validation to sanitize or reject unsafe remote file paths.
    - Compares local and remote modifications against common base revisions.
    - Fast-forwards remote changes when local has no conflicting edits.
    - Flags text conflicts when both local and remote editors modify the same file.
    - Flags binary conflicts when binary assets differ (`isBinary: true`), enforcing explicit selection without silent overwrite.
    - Flags tree conflicts when files are missing or deleted concurrently.
    - Emits visible conflict status and records audit events (`actorId`, `projectId`, `provider`, `action`, `baseRevision`, `sourceRevision`, `remoteRevision`, `resultStatus`, `conflictCount`).
  - Push synchronization:
    - Enforces strict base comparison; aborts with `REMOTE_CONFLICT` when the remote revision has advanced beyond `expectedRemoteRevision`.
    - Advances remote revision only when base matches.
  - Credential and revocation handling:
    - Rejects expired or revoked tokens with `TOKEN_EXPIRED`.
    - Handles rate limiting with `RATE_LIMITED`.
- Added comprehensive test suites:
  - `tests/integration/s13-t08.test.ts`: exercises bidirectional capabilities, connection lifecycle, fast-forward pull, text conflict detection, binary conflict enforcement, path traversal rejection, push base alignment, push conflict rejection, and token expiration.
  - `tests/regression/int-07/s13-t08.test.ts`: verifies binary conflict invariants and visible conflict audit tracking.
