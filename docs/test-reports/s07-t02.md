## Scope and acceptance evidence

- Implemented single-use ticket issuance in `apps/api/src/modules/collab/ticket.ts` via endpoint `POST /api/v1/projects/:projectId/collab-ticket`.
- Implemented single-use ticket store and validation in `apps/collab/src/auth/ticket.ts`.
- Enforced 30-second bounded TTL for tickets and atomic one-time consumption (preventing replay attacks).
- Enforced strict Origin validation against allowed application origins.
- Enforced role boundaries: OWNER and EDITOR can request write tickets; VIEWER is restricted to read tickets only (rejecting write requests with 403 `PROJECT_PERMISSION_DENIED`).
- Validated that non-existent projects/files return 404 `RESOURCE_NOT_FOUND` and binary files return 400 `VALIDATION_ERROR`.
- Added integration and regression test suites:
  - `tests/integration/s07-t02.test.ts`: verifies 30s TTL expiry, atomic single-use replay rejection, Origin header validation, file existence/content-type checks, and input schema validation.
  - `tests/regression/col-03/s07-t02.test.ts`: verifies role-based ticket issuance permissions.
  - `tests/regression/acc-02/s07-t02.test.ts`: verifies session authentication requirements and invalidation of outstanding tickets upon session revocation.
