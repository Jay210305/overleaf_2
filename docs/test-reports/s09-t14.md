# S09-T14 — Delete account under shared ownership rules

**Status:** IN_PROGRESS (task implementation complete; pending sprint completion). **Branch:** `codex/sprint-09-history-review` tracking `origin/codex/sprint-09-history-review`. **Base:** `main`. **Environment:** Linux (x86_64), Node 24+, pnpm 11.25.0, local Docker Compose PostgreSQL 17, Redis 7. **Actual effort:** 8 h.

## Scope and acceptance evidence

- Implemented account deletion workflow under shared ownership rules in `apps/api/src/modules/account/delete-account.ts`:
  - `POST /api/v1/me/delete` and `DELETE /api/v1/me`: requires authenticated session, valid CSRF token, and re-authentication with current account password verified via Argon2.
  - Enforced sole-owner protection rule: rejects deletion with HTTP `409 SOLE_OWNER_CONFLICT` if the user is owner of any active, archived, or trashed project. The user must transfer ownership or permanently delete those projects first.
  - Complete account cleanup: safely detaches user from collaborative projects owned by other users (`DELETE FROM project_members WHERE user_id = $1`), cancels pending ownership offers, cleans up user tags, invalidates verification/password tokens, revokes all active sessions in the database, and marks `users.disabled_at = NOW()` to preserve audit identity while permanently prohibiting authentication.
  - Revokes session cookie immediately on response (`Max-Age=0`).
  - Writes audit trail events `session.revoked` and `account.deleted`.
- Added contract schema `deleteAccountRequestSchema` in `packages/contracts/src/index.ts`.
- Registered route in `apps/api/src/server.ts`.
- Added comprehensive test suites:
  - `tests/integration/s09-t14.test.ts`: exercises password and CSRF authentication checks, sole ownership block (`409 SOLE_OWNER_CONFLICT`), successful deletion when unblocked, database disabling, session revocation, and cookie clearing.
  - `tests/regression/acc-07/s09-t14.test.ts`: verifies ACC-07 requirement that shared-project ownership blocks deletion until ownership is transferred to another collaborator.
  - `tests/regression/acc-02/s09-t14.test.ts`: verifies ACC-02 requirement that all sessions in user inventory are revoked and opaque cookies cleared.
