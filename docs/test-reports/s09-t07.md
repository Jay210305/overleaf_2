## Scope and acceptance evidence

- Verified concurrent suggestion resolution and file change mechanics:
  - Acceptance races: tested simultaneous conflicting resolution attempts on the same suggestion; PostgreSQL row-level locks guarantee exactly one accept operation succeeds while concurrent attempts yield 409 `SUGGESTION_CONFLICT`, eliminating double-application risks.
  - Concurrently deleted/modified files: verified that resolving suggestions on deleted or changed files safely marks the suggestion status as `conflict` and returns 409 without corrupting state.
  - Reviewer permission invariants (COL-08): verified that users with the `REVIEWER` role cannot directly alter canonical document text or invoke proposal resolution (denied 403).
  - Explicit conflict resolution (COL-09 / COL-12): verified that bulk resolution cleanly segments accepted changes and conflicts, isolating conflicting client proposals.
- Added comprehensive test suites:
  - `tests/integration/review-concurrency.test.ts`: exercises concurrent accept race conditions and target file deletion conflicts.
  - `tests/integration/s09-t07.test.ts`: exercises hash mismatch conflict handling and role enforcement against reviewer direct resolution.
  - `tests/regression/col-08/s09-t07.test.ts`: verifies COL-08 requirement that reviewer mode prohibits direct restore or direct resolution.
  - `tests/regression/col-09/s09-t07.test.ts`: verifies COL-09 requirement that repeat resolution of accepted suggestions returns 409.
  - `tests/regression/col-12/s09-t07.test.ts`: verifies COL-12 recovery semantics under concurrent client conflicts.
