## Scope and acceptance evidence

- Verified typed contract conformance across all supported and optional provider adapters:
  - `ZoteroSyncAdapter`: verified `list`, `pull`, and `individualReferenceImport`; confirmed `push` is unsupported (`CAPABILITY_UNSUPPORTED`).
  - `OptionalReferenceProviderAdapter` (`crossref`): verified open bibliographic metadata retrieval and individual reference import; confirmed `push` is unsupported.
  - `DropboxExportAdapter`: verified manual frozen source export; confirmed `pull` is unsupported in manual export mode.
  - `DropboxBidirectionalAdapter`: verified `list`, `pull`, and `push` capabilities with base comparison and explicit conflict detection.
- Deterministic error handling verification:
  - `CREDENTIALS_MISSING`: empty or absent authorization tokens produce immediate safe errors without initiating external network calls.
  - `TOKEN_EXPIRED`: expired or revoked tokens return non-retryable 401 error representations across all providers.
  - `RATE_LIMITED`: HTTP 429 status codes produce retryable error responses (`retryable: true`).
  - `CAPABILITY_UNSUPPORTED`: unpermitted actions or provider capabilities are rejected safely.
  - `REMOTE_CONFLICT`: non-fast-forward divergence on Dropbox export or sync is detected without destructive overwrite.
  - `PROVIDER_UNAVAILABLE`: network connectivity failures or remote 5xx responses produce retryable provider errors.
- Unpermitted provider segregation (INT-04):
  - Verified that Mendeley and Papers are marked as `BLOCKED_BY_PROVIDER` and return `CAPABILITY_UNSUPPORTED` across all methods without claiming fake DONE.
- Credentialed staging isolation:
  - Checked environment credential presence (`ZOTERO_STAGING_API_KEY`, `DROPBOX_STAGING_ACCESS_TOKEN`); when credentials are not configured, verified that missing access is handled with explicit `BLOCKED_BY_CREDENTIALS` or skipped gracefully without claiming fake DONE.
- Added comprehensive test suites:
  - `tests/integration/provider-contracts.test.ts`: exercises adapter lifecycle conformance, error fixtures, and staging credential checks.
  - `tests/integration/s13-t06.test.ts`: exercises HTTP status mapping (401, 409, 429, 500) and provider capability segregation.
  - `tests/regression/int-03/s13-t06.test.ts`: validates token redaction in error messages and sync results.
  - `tests/regression/int-04/s13-t06.test.ts`: verifies BLOCKED_BY_PROVIDER enforcement for Mendeley and Papers.
  - `tests/regression/int-07/s13-t06.test.ts`: validates non-retryable REMOTE_CONFLICT classification for Dropbox.
