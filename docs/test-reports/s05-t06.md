# S05-T06 — Create minimal versioned internal templates

**Status:** IN_PROGRESS, implementation complete 2026-10-16; independent co-maintainer review pending. **Branch:** `codex/sprint-11-visual-editor` tracking `origin/codex/sprint-11-visual-editor`. **Environment:** Windows, Node 24.20.0, pnpm 11.25.0, local PostgreSQL/Redis/MinIO. **Actual effort:** Not measured in hours.

## Scope and acceptance evidence

- Two original code-versioned templates in `apps/api/src/modules/templates/catalog.ts` (`minimal-article` and `thesis-outline`, `1.0.0`, `article`/`thesis` categories): file sources with SHA-256 content hashes and a manifest hash recomputed at load, so any source change alters the manifest. Templates carry no members or external authorization by construction.
- `instantiateTemplate` creates a member-free project owned solely by the requester in one transaction (project, parent-before-child tree, seq-1 canonical Yjs updates, `mainFileId`); title validation reuses the project validator.
- `GET /api/v1/templates` (session, optional `category` filter) and `POST /api/v1/templates/:templateId/instantiate` (session, `{title}`, 201 with project/template/version/main-file IDs; 404 unknown, 400 bad title, 401 missing session) in `apps/api/src/modules/templates/routes.ts`, registered in `server.ts`. The session guard prefix in `require-session.ts` now also covers `/api/v1/templates/*`; S02 suites re-run clean (11 files, 37 tests). Template DTOs added to `@latex-collab/contracts`.
- `TemplateCatalogue` in `apps/web/src/features/templates/catalogue.tsx`: versioned cards with file manifests, category filter, per-template title input, instantiate with inline failure reporting and no phantom projects.
- `tests/integration/s05-t06.test.ts` (3 jsdom tests): versioned listing, category filtering with credentialed fetch, instantiate flow with title and failure-without-phantom.
- `tests/integration/s05-t06-assets.test.ts` (4 live tests): manifest listing/filtering, editable member-free instantiation with Yjs replay of `main.tex`, unknown/bad-title/session denials.
- `tests/regression/pro-02/s05-t06.test.ts`: owned project creation with replayable `main.tex` and zero members.
- `tests/regression/pro-11/s05-t06.test.ts`: stable versions, recomputable manifest hashes, file-level preview manifests, byte-identical repeat listings.
