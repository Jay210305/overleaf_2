## Scope and behavior

- Implemented `apps/api/src/modules/projects/clone.ts` and enhanced `apps/api/src/modules/projects/create.ts` and `routes.ts`.
- `POST /api/v1/projects/:projectId/clone`: deep clones source project structure, file nodes and text document tracking. Requires `Idempotency-Key` header (16 to 128 characters) and `projectAction: "READ"`. Sets cloned project owner to current user, preserves compiler, description and hierarchy, but strictly excludes memberships, invitations, share links and secrets.
- `POST /api/v1/projects` with `templateId`: clones the existing active template project into a new project owned by the user.
- Project renaming via `PATCH /api/v1/projects/:projectId` persists updated title, timestamps and ownership while rejecting unsafe names.
