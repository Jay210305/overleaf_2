# S06-T06 — Persist verified artifacts and job result

**Status:** IN_PROGRESS (artifact persistence complete; pending sprint completion). **Branch:** `codex/sprint-06-trusted-compilation` tracking `origin/codex/sprint-06-trusted-compilation`. **Base:** `origin/main` at `35a9d57`. **Environment:** Linux (x86_64), Node 24.19.0, pnpm 11.25.0, local Docker Compose PostgreSQL 17, Redis 7, MinIO and Mailpit. **Actual effort:** 8 h.

## Scope and acceptance evidence

- Implemented `apps/jobs/src/compilation/artifacts.ts`:
  - `isValidPdf`: validates `%PDF-` (0x25, 0x50, 0x44, 0x46, 0x2D) magic header on binary output artifacts.
  - `persistJobArtifacts`: safely uploads `output.pdf`, `compile.log`, and `output.synctex.gz` into private S3 storage under `projects/:projectId/artifacts/:jobId/*`.
  - Transactionally creates or updates `artifact_sets` database record with documented retention (`expires_at`), immutable `source_hash`, and links to the compile job.
  - Replaying or retrying artifact persistence is strictly idempotent and does not create duplicate rows or duplicate success states.
  - Rejects corrupted or non-PDF output named `output.pdf` by throwing `PdfValidationError`.
- Integrated artifact persistence into `CompilationWorker`:
  - Upon executor success, automatically persists artifacts to storage and records artifact set metadata.
  - Catches `PdfValidationError` when non-PDF bytes are produced, failing closed with error code `INVALID_PDF_ARTIFACT` and `pdfAvailable = false`.
- Implemented HTTP API endpoints in `apps/api/src/modules/compilations/routes.ts`:
  - `GET /api/v1/projects/:projectId/compilations/:jobId/artifacts`: returns artifact list metadata with sha256, mime type, size, expiry, and download URLs.
  - `GET /api/v1/projects/:projectId/compilations/:jobId/artifacts/:artifactName`: securely streams private PDF, log, or SyncTeX bytes to authorized callers (`OWNER`, `EDITOR`, `REVIEWER`, `VIEWER`), enforcing `projectAction: "READ"`.
  - Denies unauthenticated (401) and foreign/outsider (404) requests.
- Added test suites:
  - `tests/integration/s06-t06.test.ts`: validates magic header verification, private S3 artifact persistence, retry idempotency, worker failure on corrupt PDF, and authorized HTTP artifact download.
  - `tests/regression/cmp-01/s06-t06.test.ts`: ensures compiler produces genuine private stored PDFs with `%PDF-` header.
  - `tests/regression/cmp-09/s06-t06.test.ts`: verifies private storage of allowed PDF, log, and SyncTeX artifacts with documented retention period and expiration timestamp.
  - `tests/regression/nfr-06/s06-t06.test.ts`: validates that persisted artifact sets bind immutably to the source revision manifest hash and survive subsequent project node edits.
