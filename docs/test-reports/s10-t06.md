- Implemented environment pairing, folding, and completion helpers in `packages/editor/src/completion.ts`:

  - `extractLabels`: extracts all `\label{...}` targets across the document.
  - `getEnvironmentFoldRanges`: calculates balanced `\begin` and `\end` spans for code folding without modifying source text.
  - `getCompletionContext`: analyzes preceding cursor token to detect `command`, `environment`, `label`, `citation`, `file`, or `image` contexts.
  - `completeAtCursor`: provides filtered suggestion lists populated from built-in standard LaTeX commands/environments and project-provided files, citations, and labels.
