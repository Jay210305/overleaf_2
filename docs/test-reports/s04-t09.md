## Scope and behavior

- Implemented `apps/api/src/modules/text/update-store.ts`:
  - `UpdateStore` managing sequential CRDT update commits into `crdt_updates`, snapshot compaction into `crdt_snapshots`, and crash recovery replay.
  - Per-file lock allocating monotonic sequence numbering without gaps or concurrent allocation races.
  - Compaction and snapshot verification: snapshots compute content SHA-256 and verify exact document re-encoding before pruning covered updates.
  - Snapshot + delta replay reconstructs exact canonical document state and matching hash after process restart or simulated crash.
  - Verified Yjs CRDT idempotency: duplicate replayed updates never cause duplicate text insertions.
