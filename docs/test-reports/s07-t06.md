## Scope and acceptance evidence

- Implemented `TreeEventSynchronizer` in `apps/collab/src/tree-events.ts` and integrated it with `CollabServer`.
- Enforced room stability across file renames: renaming a file updates file paths but preserves the underlying `fileId` and room ID `project:${projectId}:file:${fileId}`, keeping open collaboration connections alive and intact.
- Enforced safe file deletion handling: `file.deleted` marks the room as deleted, closes all open client WebSocket connections with code 4404 (`FILE_DELETED`), and rejects any future writes or ticket requests for the deleted file.
- Enforced version gap detection: detects missing tree events (`incomingVersion > currentVersion + 1`) and flags `reconcileRequired: true` to trigger client-side REST tree refresh.
- Added integration and regression test suites:
  - `tests/integration/s07-t06.test.ts`: verifies rename room continuity, delete room closure with code 4404, and tree version gap detection.
  - `tests/regression/pro-04/s07-t06.test.ts`: verifies tree mutation propagation and rejection of operations on deleted files.
  - `tests/regression/col-12/s07-t06.test.ts`: verifies concurrent edits during rename merge correctly without lost data.
