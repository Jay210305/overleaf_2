# S06-T07 — Parse diagnostics and compile failures

**Status:** IN_PROGRESS (diagnostics parsing complete; pending sprint completion). **Branch:** `codex/sprint-06-trusted-compilation` tracking `origin/codex/sprint-06-trusted-compilation`. **Base:** `origin/main` at `35a9d57`. **Environment:** Linux (x86_64), Node 24.19.0, pnpm 11.25.0, local Docker Compose PostgreSQL 17, Redis 7, MinIO and Mailpit. **Actual effort:** 8 h.

## Scope and acceptance evidence

- Implemented `@latex-collab/latex` package and `packages/latex/src/parse-log.ts`:
  - `parseLatexLog`: parses raw compiler logs and stdout into typed `Diagnostic[]` with `severity`, `filePath`, `line`, and `message`.
  - Supports `file-line-error` formatting (`path:line: error message`), standard TeX error blocks (`! error` followed by `l.line`), LaTeX warnings (`LaTeX Warning: ... on input line X`), package warnings (`Package <pkg> Warning: ...`), and bad boxes (`Overfull \hbox ...`).
  - `redactHostPaths`: strips host and container temporary path prefixes (e.g. `/tmp/`, `/work/input/`, `/home/`) and maps them to relative project paths (`main.tex`).
  - `redactSecrets`: strips database URLs (`postgres://`, `redis://`, `s3://`), Bearer tokens, JWT tokens, passwords, and API keys from compiler output to protect against log leaks (NFR-10).
- Integrated `parseLatexLog` into `TrustedWorkerExecutor`:
  - Automatically parses stdout/stderr and `main.log` upon compiler run termination.
  - Accurately populates diagnostics on compilation failures and warnings.
- Added test suites:
  - `tests/integration/s06-t07.test.ts`: validates file-line-error diagnostics, TeX error block line resolution, LaTeX/package warnings, bad boxes, host path redaction, and `TrustedWorkerExecutor` diagnostic extraction.
  - `tests/regression/cmp-02/s06-t07.test.ts`: validates that clean diagnostics and logs never reveal host or container mount directories.
  - `tests/regression/edt-07/s06-t07.test.ts`: validates accurate identification of files and line numbers for editor warning/error navigation.
  - `tests/regression/nfr-10/s06-t07.test.ts`: ensures database passwords, authentication tokens, and private secrets are strictly redacted from application compiler outputs.
