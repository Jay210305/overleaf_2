# S13-T05 — Import editable individual references

**Status:** PASS. **Branch:** `codex/sprint-13-reference-providers` tracking `origin/codex/sprint-13-reference-providers`. **Base:** `codex/sprint-11-visual-editor`. **Environment:** Linux (x86_64), Node 26+, pnpm 11.25.0. **Actual effort:** 6 h.

## Scope and acceptance evidence

- Added typed schemas in `packages/contracts/src/provider.ts`:
  - `importReferenceEntrySchema`: validates entry citation key, rawSource, and optional metadata fields.
  - `importReferencesRequestSchema`: validates provider name, targetFileId, connectionId, entry list, and normalize flag.
  - `importReferencesResponseSchema`: reports success, count, keys, targetFileId, duplicate key list, and updated file content.
- Implemented `registerReferenceImportRoutes` in `apps/api/src/modules/references/import.ts`:
  - Enforces server-side authorization: route guarded with `projectAction: "EDIT"`; viewers and reviewers receive 403 `PROJECT_PERMISSION_DENIED`.
  - Verifies provider capabilities: only providers with `individualReferenceImport: true` (e.g. Zotero, Crossref) are accepted; Dropbox is rejected with 422 `CAPABILITY_UNSUPPORTED`; Mendeley/Papers are rejected with 422 `CAPABILITY_UNSUPPORTED` / `BLOCKED_BY_PROVIDER`.
  - Verifies connection ownership and status: expired or revoked connection credentials return 401 `TOKEN_EXPIRED`.
  - Target `.bib` file resolution: finds existing `.bib` node or creates `references.bib` atomically.
  - Duplicate key detection (INT-01): parses existing `.bib` text and reports duplicate keys non-destructively without overwriting.
  - Source preservation (INT-08): preserves exact source formatting, macros, and comments when appending references; only normalizes when `normalize: true` is explicitly requested.
  - Durability and collaboration: updates the canonical Yjs document and commits sequential CRDT update frames so connected clients receive live changes.
- Added comprehensive test suites:
  - `tests/integration/s13-t05.test.ts`: exercises source preservation, duplicate key reporting, safe normalization, provider capability rejection (Dropbox), unpermitted provider rejection (Mendeley), token expiry (401), and project permission gating (403).
  - `tests/regression/int-01/s13-t05.test.ts`: validates duplicate key detection across case variations.
  - `tests/regression/int-08/s13-t05.test.ts`: verifies source preservation of comments, macros, and exotic formatting.
  - `tests/regression/int-03/s13-t05.test.ts`: verifies Zotero individual reference import capabilities and read-only push invariants.
