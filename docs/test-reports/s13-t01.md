# S13-T01 — Define provider adapter and connection lifecycle

**Status:** PASS. **Branch:** `codex/sprint-13-reference-providers` tracking `origin/codex/sprint-13-reference-providers`. **Base:** `codex/sprint-11-visual-editor`. **Environment:** Linux (x86_64), Node 26+, pnpm 11.25.0. **Actual effort:** 8 h.

## Scope and acceptance evidence

- Implemented typed provider adapter contracts and Zod schemas in `packages/contracts/src/provider.ts` and re-exported through `packages/contracts/src/index.ts`:
  - `ProviderCapabilities` (`list`, `pull`, `push`, `individualReferenceImport`).
  - `ProviderError` with standard codes: `PROVIDER_UNAVAILABLE`, `CREDENTIALS_MISSING`, `TOKEN_EXPIRED`, `CAPABILITY_UNSUPPORTED`, `REMOTE_CONFLICT`, `RATE_LIMITED`.
  - `ProviderResult<T>` discriminated union (`{ ok: true, value } | { ok: false, error }`).
  - `Resource`, `SyncInput`, `SyncConflict`, and `SyncResult` schemas.
  - `ProviderAdapter` typed interface for lifecycle and synchronization.
  - Connection lifecycle schemas: `externalConnectionViewSchema`, `connectProviderRequestSchema`, `connectProviderResponseSchema`, `refreshConnectionResponseSchema`, `projectIntegrationViewSchema`, and `linkProjectIntegrationRequestSchema`.
- Implemented authenticated credential encryption and external connection lifecycle in `apps/api/src/modules/integrations/connections.ts`:
  - AES-256-GCM encryption with randomized IVs and auth tags (`enc:v1:<iv>:<tag>:<ciphertext>`); raw secrets are never written to disk, database, or returned over API.
  - Connection endpoints: `GET /api/v1/integrations/connections`, `POST /api/v1/integrations/connections/:provider/connect`, `POST /api/v1/integrations/connections/:connectionId/refresh`, `DELETE /api/v1/integrations/connections/:connectionId`.
  - User connection isolation: users can only view and manage their own connections.
  - Token rotation support via `/refresh` endpoint.
  - Project integration linking: `GET /api/v1/projects/:projectId/integrations`, `POST /api/v1/projects/:projectId/integrations`, `DELETE /api/v1/projects/:projectId/integrations/:integrationId`.
  - Separation between user connection and project permission: project linking requires EDIT permission and enforces that the connection belongs to the requesting actor.
  - Unpermitted providers (such as Mendeley or Papers) return 422 `CAPABILITY_UNSUPPORTED` with `BLOCKED_BY_PROVIDER` error detail.
- Added comprehensive test suites:
  - `tests/integration/s13-t01.test.ts`: exercises schemas, AES-256-GCM encryption/decryption, connection creation, token protection, user isolation, token rotation, unpermitted provider rejection, and project linking/unlinking authorization.
  - `tests/regression/int-03/s13-t01.test.ts`: validates Zotero capability invariants, credential encryption, and safe view serialization excluding secrets.
  - `tests/regression/int-04/s13-t01.test.ts`: verifies Mendeley/Papers capability restrictions and `BLOCKED_BY_PROVIDER` error mapping.
  - `tests/regression/int-07/s13-t01.test.ts`: validates Dropbox capability model and synchronization conflict schemas.
