# S08-T02 — Bounded hashed share links

**Status:** DONE; the user confirmed review of this Sprint 08 slice on 2026-10-15. **Branch:** `codex/sprint-08-sharing-comments-chat` tracking `origin/codex/sprint-08-sharing-comments-chat`. **Base:** `a568117` (`origin/main`, after S07). **Environment:** Windows, Node 24.20.0, pnpm 11.25.0, local Docker Compose PostgreSQL/Redis/Mailpit. **Actual effort:** Not measured.

## Implemented and observed

- OWNER creates, lists and revokes links. A 32-byte random token is returned once and only its SHA-256 hash is stored. The request allows EDITOR/REVIEWER/VIEWER, a future expiry within 30 days and optional 1–10,000 use cap. List and later responses omit token/hash.
- A verified account redeems through a strict JSON body with exact Origin, session and CSRF. PostgreSQL project/link locks serialize use-count checks and membership changes. Independent active memberships cannot be replaced by a link.
- Migration `0010-share-link-grants.sql` ties redeemed memberships to their source link and defines `active_project_members`. REST authorization, dashboard listings, text/checkpoint/upload checks and new WSS handshake use that view. Expiry and revocation deny later requests even when the stored membership row still exists. Revocation also sets derived membership `revoked_at` transactionally.
- After a link expires, a later owner invitation can create an independent membership. S08-T01 invitation acceptance now clears the old link source on that transition.
- The two static OpenAPI copies and typed DTOs describe body redemption under ADR-011 and contract version 3.0.0. A concurrent full-suite run exposed a preexisting S05 test's global-count race; that assertion now counts only its own actor's projects.
- Share-link creation and redemption use the shared Redis-backed API rate-limit scope. A fake-limiter denial test initially passed, but a subsequent real Redis Edge journey found both scopes absent from the Redis limit table and returned 503. A real Redis regression failed first and then passed after registering both scopes (10 creates and 20 redemptions per window); the Edge journey passed afterward.
