# S05 Upload Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task by task. Steps use checkbox syntax for tracking.

**Goal:** Remove expired upload staging objects and unreferenced project blobs without deleting current, revision or artifact data; verify concurrent upload quota enforcement.

**Architecture:** A private jobs process scans only known project `uploads/` and `blobs/` prefixes. Before deletion it rechecks object age, holds the project row lock and searches all durable object references, including active upload intents. The upload API remains the authority for byte and node quotas.

**Tech Stack:** Node 24, TypeScript, PostgreSQL 17, S3-compatible MinIO, Vitest, pnpm 11.25.0.

**Spec:** `implementation/sprint-05-assets-import-export/S05-T09-implement-quota-and-orphan-object-cleanup.md` and `docs/contracts/storage-and-revisions.md`.

## Global Constraints

- Scan private project keys only; never take object keys or project IDs from a public request.
- Delete only after the 300-second signed PUT window and a 10-minute minimum object age.
- Keep the 25 MiB file, 100 MiB project and 2,000-node limits enforced at upload completion.
- Current nodes, immutable revision items/manifests, artifact sets and unexpired upload intents are references.
- S05-T01 independent review is pending; S05-T09 cannot be marked done until its dependency is accepted.

## Review Focus

- A second worker must not delete a blob while an upload using the same hash is in progress; test an unexpired pending intent.
- A deleted or inaccessible project must remain untouched; test unknown project keys and use only DB-listed projects.
- A storage delete failure must be retried on a later pass; test failure and successful retry.
- Old revision and artifact references must protect blobs after current nodes disappear; test each reference source.
- Two concurrent completions near the project byte cap must commit at most one node; test the API transaction boundary.
