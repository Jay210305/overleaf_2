# Progress and Evidence Context

Inputs: selected task, actual implementation/diff and observed commands/results.
Process: update the relevant stage matrix, [global log](progress-log.md), [feature evidence](../feature-parity.md), [gaps](open-gaps.md) or [debt](technical-debt.md). Synchronize changed task status with the task index/roadmap.
Outputs: dated evidence, actual hours when observed, precise blockers and next Ready work.
Human check: estimates, written plans, installed skills and document checks do not establish product completion. Record `NOT_RUN` when applicable. Follow [Agent Workflow](../agent-workflow.md).
