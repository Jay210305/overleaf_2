# Development Tooling and Environment Contract

## Commands

S00 now supplies frozen installation, formatting/lint/types/coverage, app/package builds, generated local env, real Compose services/private bucket, browser/API dev startup and smoke checks. See [S00 verification](../test-reports/s00-verification.md). Migration, seed, collaboration and compiler commands remain later task interfaces; no implementation is claimed for them.

| Command | Input / output | Exit / behavior |
|---|---|---|
| `pnpm install --frozen-lockfile` | Pinned workspace manifests and lockfile / installed dependencies | 0 success; nonzero mismatch; no implicit lockfile update |
| `pnpm infra:up` / `pnpm infra:down` | Compose config / PG Redis MinIO Mailpit start or graceful stop | 0 healthy/stopped; nonzero missing Docker/config; no deletion of persistent volumes by default |
| `pnpm db:migrate` | DATABASE_URL + reviewed SQL / migration report | 0 applied; nonzero failure/rollback; no production auto-reset |
| `pnpm db:seed` | Explicit development/test environment / role/sample fixtures | 0 seeded; nonzero production environment refusal |
| `pnpm dev` | Valid local env / web API and applicable collab/jobs logs | Long-running; useful readiness; nonzero startup error |
| `pnpm --filter @latex-collab/api invite:trusted <email> <display name>` | Reviewed trusted recipient plus DATABASE_URL, SMTP_URL and EMAIL_FROM / invitation email | 0 only after SMTP acceptance; nonzero on invalid recipient, existing registered account or provider failure; never prints the secret token. Registration/verification remain S02-T01 in progress. |
| Quality scripts | See QG-01–QG-09 in planning doc 06 | 0 pass; nonzero failures, unavailable dependency or unimplemented script |
| `python scripts/plan_lint.py` | Current Markdown plan / consistency report | 0 structural pass; 1 errors; no product-test claim |

Pin Node LTS compatibility and pnpm in manifests/lockfile after research; expose deterministic no-network unit tests. Compose uses MinIO S3 and Mailpit for local emails. No real emails or credentials are required for fixture suites.

## Variables

| Visibility / service | Variables | Validation |
|---|---|---|
| Browser, public | VITE_API_URL, VITE_COLLAB_URL, VITE_APP_NAME | HTTP(S)/WSS URLs and name; no secrets |
| API / server | NODE_ENV, APP_ORIGIN, API_PUBLIC_URL, COLLAB_PUBLIC_URL, PORT | Environment enum, exact allowed URL origins, PORT integer |
| API DB/cache | DATABASE_URL, REDIS_URL | Private server URLs; redact connection credentials |
| Server security | SESSION_SIGNING_KEY, TICKET_SIGNING_KEY, CRYPTO_ENCRYPTION_KEY | Injected high-entropy secrets; at least 32 bytes; rotate with documented key ID |
| Email | EMAIL_FROM, SMTP_URL, RESEND_API_KEY | Mailpit SMTP locally; Resend HTTPS takes precedence when its server-only key is configured. Both transports require EMAIL_FROM. See [hosted email setup](../operations/hosted-email.md). |
| Object adapter | S3_ENDPOINT, S3_REGION, S3_BUCKET, S3_ACCESS_KEY_ID, S3_SECRET_ACCESS_KEY | Private server-only mapping to actual provider values |
| Origin/trust | CORS_ALLOWED_ORIGINS, PUBLIC_SIGNUP_ENABLED, UNTRUSTED_COMPILE_ENABLED, COMPILER_EXECUTION_MODE | Exact origins; booleans false initially; trusted_worker/isolated enum |
| Quotas | MAX_UPLOAD_MB, MAX_PROJECT_MB, MAX_COMPILES_PER_USER | Starting proposals 25, 100, 1; actual bytes checked and finite positive values |
| Logs | LOG_LEVEL | Allowlisted level, redaction enforced |
| Jobs | COMPILE_QUEUE_NAME, COMPILER_EXECUTOR_URL, COMPILER_EXECUTOR_SHARED_AUTH, TEXLIVE_IMAGE_DIGEST, DEFAULT_COMPILE_TIMEOUT_SECONDS | Private execution identity/URL, pinned digest, proposed latex-compiles and 60 s |

Optional settings introduced by this plan: MAX_FILES_PER_PROJECT=2000, COMPILE_MEMORY_MIB=512, COMPILE_CPU_CORES=1, MAX_COMPILE_OUTPUT_MB=25, SIGNED_GET_TTL_SECONDS=60, SIGNED_PUT_TTL_SECONDS=300, WSS_TICKET_TTL_SECONDS=30, ARTIFACT_RETENTION_DAYS=14, LOG_RETENTION_DAYS=7. Each is a validated bounded starting proposal and must be measured, not a platform guarantee.

Inject only minimal required secrets into each service. TeX runtime gets frozen input/policy and bounded output channel, not DATABASE_URL, REDIS_URL, session keys or general bucket credentials. `.env.example` contains placeholders only; never check in a real .env. Validate production values at startup and reject untrusted mode without verified isolation policy.

## Valid and Invalid Examples

Valid: development Compose plus local .env generated by contributor permits migration/seed; browser configuration lists only public URLs.

Invalid: `NODE_ENV=production pnpm db:seed` with fixed fixture credentials → nonzero refusal. Missing DATABASE_URL → startup exits nonzero before listening. `VITE_DATABASE_URL` → secret/boundary check fails. Public flag true with trusted_worker executor → fail-closed configuration error.
